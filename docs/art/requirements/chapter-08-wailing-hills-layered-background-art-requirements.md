## 1. 章节定位

第八章从冷暗海底进入风化、空旷的「哀嚎丘陵」。这里表现的是长期受风侵蚀的荒丘、被草土掩埋的旧战坡地和无铭丘墓，不是血腥战场或恐怖墓园。战斗始终发生在宽阔、连续、可读的实体地面上：

1. `8-1`～`8-4`：低、横、风化的枯风荒丘；
2. `8-5`～`8-8`：层叠、侧压、残迹克制的旧战坡地；
3. `8-9`～`8-12`：冷静、秩序明确的丘墓禁地。

三套地图通过丘陵体量、枯植被、旧土垒和无文字石构件建立递进。关卡名称与敌人组合承担同一区域内的逐关差异；区域 Boss 连续复用四关，第 4 关只强化数值、随从与节奏，不为每关增加独立长图、固定地标、运行配置或存档字段。

## 2. 色彩与画风

- 全章天空：低饱和灰紫 `#AAA3AE`、冷云灰 `#C4C0C1`。
- 通用轮廓：深灰褐 `#494447`，保持圆润、连续，不使用纯黑。
- 枯风荒丘：风化灰棕 `#8C7D6D`、枯草灰绿 `#777662`、冷土灰 `#716B68`。
- 旧战坡地：压实土褐 `#78695E`、旧木灰棕 `#665A52`、残旗暮紫 `#756875`。
- 丘墓禁地：冷石灰 `#737376`、风化浅岩 `#AAA69D`、丘土灰紫 `#716A72`。
- 小面积提亮色：旧金灰 `#9A8A66`；只用于少量盾缘、石面或旧构件切面，不做发光色。

继续使用低饱和大色块和少量硬边暗面。每个主要形体最多一块宽暗面，不使用写实泥土纹理、密集草丝、裂纹网、碎石噪点或烟尘颗粒。

线宽层级沿用成熟标准：远侧中景约 `5～7 px`、后缘中景约 `6～8 px`、地表交界与前景约 `10～14 px`。远处的圆丘、土垒、石环与断拱仍须有低对比深色描边；天空、云带和薄风雾不描重边。不能把中景画成无边纯色块，也不能让中景与地表、前景等粗。

## 4. 三套区域地图

### 8-1～8-4：`wailing_withered_hills` 枯风荒丘

对应关卡：哀嚎隘口、枯丘坡道、骨环营地、灰烟哨站。

缩略图关键词：**低、横、空旷**。这是全章最亮、地势最平缓的一套，以两层圆钝荒丘和少量粗枯植被建立入口，不画尖锐山脊或密集枯木林。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 两层低矮圆丘、稀疏粗树影和一条宽薄风雾带；中央天际线开阔，不出现尖峰、龙卷或密集树枝 |
| `rear_v01.webp` | 两侧丘肩、少量粗叉枯树和低矮宽叶枯灌草；形体断续，中央约 45% 保持开口，不形成连续树墙 |
| `road_v01.webp` | 宽阔硬实灰棕土路，只有 2～3 块宽缓冷灰磨损和少量风化浅岩色区；不画密集裂缝、碎石或车辙网 |
| 专属前景 A | 一组粗叶枯蓟、宽草片与圆石，偏简单；叶片粗大、数量克制、左右高低不对称 |
| 专属前景 B | 低矮风化树桩、骨白浅岩和少量枯草，偏复杂；树桩保持圆钝，不形成尖刺路障 |

“骨环营地”只用低矮浅色风化石圈暗示，不画骨头；“灰烟哨站”只用薄风雾、短木桩或矮石基座暗示，不出现烟柱和完整哨塔。

### 8-5～8-8：`wailing_old_battlefield` 旧战坡地

对应关卡：旧战长路、残旗岗哨、丘墓裂谷、荒石阶地。

缩略图关键词：**层叠、侧压、旧痕**。两侧低土垒和残缺构件建立旧战场感，整体比枯风荒丘更深、更重；中央压实土路仍保持宽阔，不出现武器堆、尸体或横断道路的壕沟。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 两至三层低土垒、少量折断器械的大轮廓和宽灰紫风雾带；器械只留轮廓，不画绳索、齿轮或武器细节 |
| `rear_v01.webp` | 两侧低胸墙、粗短木桩、素面残旗和圆钝防御石；结构断续、中央留口，不形成连续栅栏或壕沟 |
| `road_v01.webp` | 宽阔压实灰褐土路，以 3～4 块大面积深浅土色建立节奏；最多两道宽而浅的旧车辙，不画泥坑、血迹或碎铁 |
| 专属前景 A | 一面无文字素色残旗、低矮旗座和圆角旧盾组合，偏简单；旗面只保留一块大色面，无徽记 |
| 专属前景 B | 半埋破车轮、低木段和枯草组合，偏复杂；车轮粗大完整可读，不加入辐条碎屑或武器堆 |

“丘墓裂谷”只在远景与道路后缘暗示坡地落差，不在主要战斗平面开裂谷；“残旗岗哨”不重复完整塔楼、长栅栏或整排旗帜。

### 8-9～8-12：`wailing_barrow_grounds` 丘墓禁地

对应关卡：哀嚎回廊、墓风祭场、丘门门庭、哀嚎之心。

缩略图关键词：**冷静、低沉、秩序**。这是全章最暗、石构感最强的一套，用低丘墓、断石环和无铭石构件建立边界，但中央战斗区保持完整，不画恐怖墓园或地下墓穴入口。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 风雾中的低矮丘墓、两侧断石环肩部和少量倾斜立石；地标压在两侧，中央不出现完整巨石门或巨大墓冢 |
| `rear_v01.webp` | 两侧无铭石碑、圆钝断拱、低丘肩和分组荆棘；结构断续，不横跨画面，不形成连续墓碑墙 |
| `road_v01.webp` | 冷灰石土路与一条宽缓浅岩行走带，使用 2～4 块大面积风化色区；不画密集砖缝、墓文、符文或透视长廊 |
| 专属前景 A | 一块低矮无铭石碑、粗叶荆棘和圆石组合，偏简单；石碑无文字、头像、十字或符号 |
| 专属前景 B | 丘墓断拱基座、风化大石和少量粗枯藤组合，偏复杂；断拱保持低矮，不构成完整门洞 |

“祭场”“门庭”和“哀嚎之心”只由丘墓体量、断石环和冷灰风雾暗示，不使用宗教符号、可读墓文、幽灵、鬼火或发光核心。

## 5. 构图和循环硬标准

- 背景生成母图为 `2172×724`；按运行目标比例居中裁切后输出 `1720×560`，不直接拉伸宽高比。
- 前景生成源图为 `1536×1024`，工作母图为 `576×384`，运行图为 `288×192 RGBA WebP`。
- 地表占母图高度约 68%～75%，上沿平均位于顶部以下约 25%～32%；丘沟、壕沟和墓穴不能切断主要行走带。
- 地表与后景交界必须有连续的深灰褐粗圆描边；母图视觉粗度约 `10～14 px`，不能出现只有色块的缺线区段。
- 远侧中景的圆丘、土垒、石环和断拱使用约 `5～7 px` 低对比描边；后缘树干、木桩、石碑和矮墙使用约 `6～8 px` 描边。云带与风雾不描重边。
- 中央约 70% 的主要行走带保持低对比；每条道路最多 3～4 处大而疏的磨损、浅岩色区或宽车辙。
- 后缘有效绘制高度约 78%～84%，中央约 45% 留口。高形体从两侧进入，不能用整排等高枯树、旗杆、石碑或断拱填满上沿。
- 左右各 10% 为循环安全区，不放完整树桩、旗帜、车轮、石环、石碑或断拱等独特物件；两端地表高度、颜色和节奏匹配。
- 前景主体占生成源图宽约 70%～82%、高约 72%～84%；底部自然搭接，上缘保留空隙、高低差和不对称轮廓。
- 前景继续采用简繁随机、水平翻转、缩放和约 `0.36～0.92` 屏的随机间隔；同一屏通常出现 1～2 片。
- 视差速度沿用现值：天空 `0.03×`、远景 `0.12×`、后缘 `0.32×`、地表 `1.00×`、前景 `1.22×`。

## 6. 禁止项

- 骷髅、明确骨骸、尸体、血迹、墓穴遗体、武器插满地面或怪物残肢；
- 幽灵、鬼火、发光眼睛、恐怖浓雾、发光符文、魔法旋涡或灵魂粒子；
- 写实泥土纹理、密集枯枝网、细碎草丝、裂纹网、碎石噪点、烟尘颗粒或强烈风沙；
- 尖刺森林、锯齿山峰、深黑墓穴入口、巨大墓冢或压满画面的石碑群；
- 重复完整哨塔、巨石门、石环、断拱、旗帜、车轮或其他会暴露循环的独特地标；
- 可读文字、墓文、宗教符号、十字、徽记、人物雕像或具象脸孔浮雕；
- 横断战斗区的裂谷、壕沟、坟坑、栅栏、断桥或单点透视道路；
- 直接生成透明像素。

所有需要透明的图层继续使用纯 `#FF00FF` 色底生成，再由现有处理程序去底，避免透明接缝毛刺。
