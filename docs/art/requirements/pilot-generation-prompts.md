# 首批模块样板生成提示词记录

**生成方式：** Codex 内置 ImageGen  
**样式参考：** `docs/art/references/hero-style-master-v1.png`  
**日期：** 2026-07-31  
**交付方式：** 先生成纯色键控背景，再使用本地键色移除工具生成 Alpha PNG。

## 共用不变量

- 超粗近黑色外轮廓，内部线条仍然粗。
- 头身比为 1.6–1.9，头部占总高 48%–55%。
- 仅两枚黑色椭圆眼睛，无嘴、鼻子、眉毛和眼白。
- 圆圈手、极短腿、极小脚。
- 4–6 个纯色，大面积扁平色块。
- 无文字、标签、水印、场景、地面和投影。
- 原创造型，不使用暴雪或《魔兽世界》特有套装、武器、徽记和界面符号。
