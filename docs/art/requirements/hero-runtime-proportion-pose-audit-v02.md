# 英雄运行时体量与持械姿势复核 v02

## 复核范围

已按当前游戏实际英雄显示尺寸约 83×83 px 复核 H01–H80。运行时对所有英雄使用同一画布尺寸和同一显示缩放；人物本体统一按 1024 px 主图中的 760 px 身体框归一化，身体中心位于 x=512，脚底线位于 y=930。

判定以人物本体为准：头部、核心躯干、圆手、短腿与脚底保持同一体量；武器、盾牌、披风尾、发尾、光环和脱离身体的法术符号不参与人物本体缩放。装备超出安全边距时缩短或重排装备，不缩小人物。描边保持同一视觉粗细，不通过放大旧位图修正体量。

## 持械硬规则

- 双持攻击武器时，两把武器的有效攻击端都位于各自握持手的画面右侧或右上方。剑尖、匕首尖、斧头工作面、拳刃尖端和枪口均满足 `攻击端 x > 对应握持手 x`，前后手用纵向错位区分，不使用左右镜像外展。
- 盾牌与攻击武器并用时，人物左手（画面右侧）拿攻击武器，人物右手（画面左侧）拿盾牌。
- 肩—肘—腕—圆手—握柄保持连续受力关系。攻击手自然下垂或略向前，不使用手臂后摆后再把武器折向前方的反关节姿势。

## 生产规则

生成提示必须同时写明人物朝向、每件武器对应的握持手，以及攻击端相对握持手的屏幕坐标关系。只写“面向右侧”不能保证武器方向正确。透明图边界识别忽略 alpha 1/255 的不可见背景噪点，避免生成器残余像素触发整画布缩放。
