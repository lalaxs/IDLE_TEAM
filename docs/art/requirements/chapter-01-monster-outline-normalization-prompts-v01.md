# 第一章怪物描边规范化提示词 v1

## 通用编辑提示词

以输入角色图为唯一造型参考，保留角色的物种、轮廓、朝向、姿势、装备、主色和既有表情，只做适配当前游戏战斗画面的美术规范化：

- 风格为可爱、简洁、低细节的 2D 手绘游戏角色，形体由少量大色块组成；
- 使用圆润、稳定的深色描边，不使用碎线、毛刺或铅笔纹理；
- 归一化后的源图外轮廓保持约 `30～34 px`、内部线约 `18～24 px`；所有敌人使用同一运行倍率，使最终外轮廓约 `3～4 px`、内部线约 `2～3 px`；
- 减少脸部纹理和装饰细节，眼睛使用单色实心形状，禁止瞳孔高光、反光点和玻璃质感；
- 使用偏低明度、偏低饱和度的自然配色，避免荧光色、高亮描边和大面积纯白；
- 不改变角色战斗识别点，不增加新器官、新装备、文字、标志、水印、底座或投影；
- 输出单角色、完整轮廓、透明背景 PNG，角色水平居中，脚底或最低接地点明确。

## 输出归一化

- 主图：`1024×1024` RGBA；
- 普通怪主体框：最大 `620×560 px`；
- 精英主体框：最大 `720×650 px`；
- Boss 主体框：最大 `880×780 px`；
- 紧凑型：使用所属类型主体框的 `88%`；第一章 E12、B12 使用紧凑型；
- 水平位置：可见边界居中；
- 最低接地点：`y=930`；
- 运行缩放：所有敌人使用同一个倍率，禁止根据单图可见边界二次放大；
- 最终验收：以实际战斗画面中的显示线宽、体量与脚底落地感为准。
