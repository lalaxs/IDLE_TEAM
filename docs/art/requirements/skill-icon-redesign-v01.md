# 技能图标统一重制规范 v01

## 结论

现有技能图标需要整套重制。

重制范围为 88 个图标：40 个专精主动技能、40 个专精被动技能、8 个通用被动。40 个专精由 80 名英雄两两共享，不需要为每名英雄重复绘制。

这次不应只做批量缩放、居中或统一套底。现图全部以透明底孤立符号绘制，主体占比、视觉重心、线条粗细和信息量没有共同基线；给它们加同一种背景只能缓解“散”，无法建立成熟游戏所需的系列感。正确做法是保留清楚的技能意象，以统一的纯色背景、粗描边、构图和配色规则重新绘制全套。

当前素材总览见 [技能图标现状联系表](../reviews/skill-icon-current-contact-sheet-v01.png)，逐图测量数据见 [技能图标现状测量](../reviews/skill-icon-current-metrics-v01.json)。

## 审查范围

- 14 张现有 `3 × 3` PNG 图集，包括 13 个职业图集与 1 个通用被动图集。
- 88 个实际被游戏引用的图标格。
- 英雄技能栏、技能选择卡与技能详情中的 30px、最高 40px、56px 三种显示尺寸。
- 项目现有的厚描边卡通英雄、装备图标、深炭灰框架、奶油纸面与圆角方形图标容器。

现图单格为 `418 × 418px`。不透明内容的横向占比从 48.6% 到 93.3%，纵向占比从 41.9% 到 91.2%；换算到 56px 图标，轮廓跨度约为 27–52px，肉眼感受到的大小接近两档。28/88 个图标的外接框中心在至少一个方向偏离画布中心超过 5%；4 个图标已经贴到单格边缘。

## 现状问题

### 1. 缺少属于技能本身的背景

当前图标是透明底符号，界面用同一个浅绿色 `#DCE9D2` 托底。火焰、冰霜、暗影、自然、治疗和防护因此共享同一种空气感，职业与技能属性只能靠中心小符号区分。浅色或细小效果还会与浅绿底相互吞没。

技能新图应自带一种满版纯色背景，四角与中心使用同一色值；UI 只负责统一外框、圆角裁切、冷却遮罩和状态反馈，不再替美术素材补底色。

### 2. 视觉大小没有共同基线

极宽或接近满格的图标包括虚空射线、杀戮凛风、龙焰贯袭、蓄势龙息、辉鳞增幅和审判重锤；明显偏小或细长的图标包括噬心低语、奥术积蓄、醉拳、祈愿之环和虚空涌动。相邻摆放时，图标看起来不是同一套资源。

### 3. 光学中心偏移

偏移最明显的图标包括醉意震掌、撕裂扑杀、剑火齐鸣、戒律护佑、盾墙猛击、蚀变、熔雷爆裂、奥能齐射、共鸣龙鳞和蓄势龙息。主要原因不是裁切坐标错误，而是上重下轻、单侧飞散物过多或长柄武器斜向伸出后没有反向配重。

裂魂烙印、撕裂扑杀、龙焰贯袭、蓄势龙息已经贴近或触及格子边缘，圆角裁切后会进一步显得局促。

### 4. 小尺寸信息过量

部分图标同时出现武器、目标、轨迹、碎片、星芒或多个重复物件。在 30–40px 下，玩家先看到的是一团线条，而不是技能动作。优先需要重新构图的代表为虚空射线、杀戮凛风、爆裂猎矛、疾风连环、剑火齐鸣、魔群召引、影袭本能、霜寒追击和雷霆共鸣。

### 5. 粗描边语言不稳定

英雄与装备已形成粗外轮廓、少量内分线、饱满色块的卡通语言；技能图标内部仍混用细箭杆、细圆环、细碎光点和不同深浅的棕黑描边。缩小后，粗轮廓留下，细线消失，导致同一图标内部结构断裂。

## 新版视觉规范

### 画布与构图

- 美术母版：`512 × 512px`，sRGB，方形。
- 运行时单图：`256 × 256px` PNG；按现有 `3 × 3` 顺序打包为 `768 × 768px` 图集。
- 背景使用一种纯色满版绘制，四角同色，不留透明外圈。UI 使用圆角方形蒙版裁切，素材本身保持直角方形，不画圆形底、圆角或外部 UI 边框。
- 主体长边占画布 66%–72%；长柄武器、射线等极端比例最多 78%。关键轮廓不得进入最外侧 8%。
- 主体光学中心与画布中心的偏差不超过 10px；允许动作方向形成轻微偏势，但必须由反向辅形或负形平衡，整体偏差不超过 16px。
- 每图只设 1 个主视觉；允许 1 个辅形。重复箭、匕首、召唤物、雨滴等必须合并成一个整体剪影，不画散落个体。
- 优先使用正面、四分之三侧或明确对角线构图；不要把多个等权物件平铺成说明图。

### 粗描边

- 主体外轮廓：母版 32–40px，约为画布宽度的 1/16，统一使用深炭灰 `#24262D`；特殊暗影技能也不改变描边颜色。
- 内部分隔线：16–20px；最细有效线不得低于 16px。缩到 56px 后应保留约 3.5–4px 外轮廓、1.75–2px 内分线。
- 轮廓端点与转角圆润，贴合现有 Q 版英雄和装备；不用锐利矢量尖角、毛笔飞白或写实金属刻线。
- 外轮廓连续，不使用发光、粒子或半透明效果覆盖主体边界。

### 色彩与背景

每个图标只使用一种满版背景色，不能再叠加圆形、斜切、条带、徽章或第二块底色。主体控制在 3–4 个颜色区域，另允许 1 个小面积纯色高光。背景禁止渐变、暗角、明暗变化、纹理、阴影与透明效果；主体禁止渐变、辉光、材质、透明叠色和空气透视。

| 技能语义 | 推荐背景纯色 | 主体高亮 |
| --- | --- | --- |
| 物理、流血、火焰 | 深绯红 `#7A1620` | 橙红、金黄、银白 |
| 冰霜、水、时间 | 深钴蓝 `#124B8C` | 冰蓝、青白、银白 |
| 自然、治疗、毒 | 森林绿 `#245B2B` | 嫩绿、乳白、粉色 |
| 圣光、防护、增益 | 深钴蓝 `#124B8C` | 金黄、象牙白、宝蓝 |
| 奥术、暗影、恶魔 | 深靛紫 `#2F1B65` | 紫晶、洋红、冷白 |
| 风、雷、机动 | 深青绿 `#174B54` | 电蓝、亮黄、青白 |

颜色表达技能力量来源，但不作为唯一语义。主动技能通常使用更明显的动作方向与冲击辅形；被动技能使用较稳定、徽记化的构图。二者仍必须靠主图形本身区分。

### 复杂度

- 在 56px 下，第一眼必须读出“盾、火球、爪击、治疗花、眼睛、双斧”等主名词。
- 主体色块控制在 3–4 块；只允许一块纯色高光，不画纹理、裂纹、刻字和多层高光。
- 不画粒子、火星、碎石、烟雾、光环、速度线或背景装饰纹样。动作方向只由主体姿态和一个辅形表达。
- 避免“主体 + 箭头 + 状态徽记 + 数量提示”的说明书式组合。层数、次数、冷却和增减益由 UI 表达，不画进技能图标。
- 不使用文字、数字、职业徽记、稀有度边框或英雄头像。

### UI 外框与状态

- 图标容器统一使用 `#24262D` 2–3px 外框、10–12px 圆角和一道浅色内高光；外框由 UI 绘制，不烘焙进图。
- 冷却与怒气遮罩必须压在美术之上，不能改变原图色相。就绪态用外圈亮边或短促脉冲，不放大图标导致相邻格跳动。
- 未解锁、阵亡和禁用状态用遮罩、锁或状态文字共同表达，不只做去色。
- 30px 仅用于信息密集的英雄技能栏；可点击技能入口的触控范围继续保持至少 44 × 44 CSS px。

## 技能意象规则

- 主动技能画“动作发生的瞬间”：命中、释放、冲击、治疗或召唤。
- 被动技能画“机制留下的稳定标记”：护壳、印记、资源、姿态、持续影响或条件触发。
- 同一专精的主动与被动共享一种背景色温、轮廓处理和一个重复造型语言；不能只靠相同颜色硬凑成套。
- 同一职业可共享材质倾向，例如死亡骑士的冷铁、德鲁伊的叶片、圣骑士的金边、术士的紫焰；不同专精仍通过主形和技能属性拉开。
- 通用被动不带任何职业专属纹章，背景饱和度略低于专精主动，保证装到任意英雄上都成立。

## 交付结构

美术先交独立母版，再由项目打包图集。建议文件名：

```text
skills/master/<spec-id>-active.png
skills/master/<spec-id>-passive.png
skills/master/shared-<skill-id>.png
```

运行时继续沿用现有职业图集：

```text
public/assets/skills/atlas-<class>.png
public/assets/skills/atlas-shared.png
```

每个职业按专精顺序依次放置主动、被动；战士图集保留当前特殊顺序：防护、武器、狂怒。德鲁伊使用前 8 格，其他职业使用前 6 格，通用被动使用前 8 格。空格保持透明。

## 生产顺序

### 第一批：12 个风格锚点

先完成以下图标，用来锁定背景、粗描边、复杂度和小尺寸表现：

- 盾墙猛击、杀戮凛风、虚空射线
- 星辰轮转、龙焰贯袭、爆裂猎矛
- 灼爆火球、醉意震掌、圣光信标
- 噬心低语、剑火齐鸣、魔群召引

这 12 个覆盖盾牌、武器、射线、多目标、元素、治疗、暗影和召唤等主要构图难题。锚点通过后，样式不再逐图漂移。

### 第二批：高曝光图标

完成 40 个专精主动技能与 8 个通用被动。它们承担战斗与技能选择中的第一识别。

### 第三批：机制图标

完成 40 个专精被动技能，并以专精对为单位检查主动/被动的共同语言与清楚差异。

## 验收标准

- 联系表中 88 个图标放在一起时，主视觉体量没有明显跳档；普通图标长边保持 66%–72%，特例不超过 78%。
- 30px、40px、56px 三档都能识别主名词；30px 下允许丢失纯色高光，不允许丢失主体。
- 图标套用 12px 圆角蒙版后，关键轮廓、武器尖端、龙首、盾面和技能焦点不被裁切。
- 背景取样只有一个色值；四角不得出现透明、渐变、暗角、第二色块或预制圆角。
- 每张图在深炭灰 HUD 与奶油纸面详情中都保持主体清楚，背景不会与 UI 外框融成一块。
- 同一专精的主动/被动成对成立；同职业成组成立；通用被动不偏向某一职业。
- UI 冷却遮罩、就绪外圈、禁用遮罩叠加后，图标仍可识别且不会改变布局尺寸。
- 图集索引与现有映射一致；替换后不需要修改技能数据和存档结构。

## 美术需求摘要

> 以《青丘远征》现有 Q 版英雄与装备图标为基准，重绘一套带满版纯色背景的极粗描边扁平技能图标。每图一个主视觉、一个明确动作或机制，外描边约占画布宽度 1/16，主体只用 3–4 个纯色色块。背景整张只用一个色值，四角同色，不画圆形、斜切、渐变、暗角、纹理或预制圆角；圆角由 UI 裁切。主体光学居中、大小统一，在 30–56px 下仍能辨认。禁止辉光、阴影、材质、透明效果、粒子、多个等权物件、文字数字和内置 UI 边框。

## 限制

本轮完成了资源、代码尺寸与现有界面截图审查，没有替换运行时图集。新版风格应先通过 12 个锚点图标，再进入 88 个图标的完整生产。
