# 第四章「雷崖高地」分层战斗场景美术需求确认稿

状态：**三套区域资源已生成、接入并完成 `4-1`、`4-5`、`4-9` 实机抽查**

第四章继续使用第一至第三章已经验证的横版分层地图工作流。视觉基准是当前游戏内 `1-1` 与第二、三章成品；旧版第四章合成背景只用于识别云海、高地和天城题材，不作为构图、透视或细节密度参考。现有 UI、交互、战斗逻辑和存档结构保持不变。

## 1. 章节定位

第四章从赤沙荒地登上高空岩陆，正式题材为「雷崖高地」。保留云海、少量浮石和高空要塞，但所有战斗都发生在宽阔、连续的实体地面上，不做轻飘的梦幻天空岛：

1. `4-1`～`4-4`：开阔、横展、明亮的云崖高原；
2. `4-5`～`4-8`：高耸、侧压、偏冷的风暴峡谷；
3. `4-9`～`4-12`：厚重、垂直、秩序明确的苍雷要塞。

章节辨识依靠高地体量、风暴云带、暖白石构与少量旧铜结构。关卡名称与敌人组合承担同一区域内的逐关差异；区域 Boss 连续复用四关，第 4 关只强化数值、随从与节奏，不为每关增加独立地标或背景配置。

## 2. 色彩与画风

- 全章天空：灰青 `#B8CACA`、暖云灰 `#D7D3C8`。
- 通用轮廓：深灰棕 `#4A4038`，保持厚、圆润、连续。
- 云崖高原：灰薄荷 `#879680`、暖白岩 `#C7BBA4`、浅灰紫 `#98909B`。
- 风暴峡谷：板岩紫灰 `#756E7D`、深灰蓝 `#66747B`、鼠尾草绿 `#77816C`。
- 苍雷要塞：暖白石 `#BDB3A1`、深青绿 `#506760`、旧铜 `#91745A`、冷灰影 `#77777A`。

继续使用低饱和大色块与少量硬边暗面。每个主要形体最多一块宽暗面，不使用写实石纹、密集云纹、渐变噪点或细碎笔触。远侧中景使用约 `5～7 px` 的低对比描边，后缘中景使用约 `6～8 px` 的圆描边，地表和前景再加重；云、雾与天空不描重边。

雷电不直接画成重复出现的亮色闪电。雷崖感主要由灰紫风暴云、风压植被、旧铜导风构件和高地要塞轮廓建立，避免静态闪电与战斗特效冲突。

## 3. 资源范围

全章共制作 **10 张背景层和 8 个模块化前景**：

- 1 张全章共用天空；
- 3 套区域各 1 张远景、1 张后缘、1 张地表；
- 2 个全章通用前景；
- 3 套区域各 2 个专属前景。

运行时只加载当前区域的四层背景与四个前景物件。继续使用现有双图镜像循环、分层视差和前景随机布局，不增加逐关长卷、A/B 段配置、天气系统、存档字段或迁移模块。

## 4. 三套区域地图

### 4-1～4-4：`thundercliff_highlands` 云崖高原

对应关卡：云门栈道、浮石坡径、风铃驿站、断虹平台。

缩略图关键词：**低、横、开阔**。这是三套地图中最亮、最平缓的一套，表现云海之上的实体高原入口，而不是悬空平台。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 两层横向高原与位于低侧边的宽云海，岩体大而圆缓；中央天际线保持开阔 |
| `rear_v01.webp` | 两侧低矮暖白岩肩、灰薄荷矮树和少量栈道端部；桥梁不横跨中央 |
| `road_v01.webp` | 灰薄荷硬草地与暖灰白岩路混合，只保留 2～3 处宽缓磨损色块；不画通向地平线的道路 |
| 专属前景 A | 层叠暖白石灰岩与低矮风草，偏简单 |
| 专属前景 B | 大片薄荷宽叶与少量淡灰紫圆花，偏复杂；花朵不碎、不密 |

少量浮石只能出现在远景两侧，以 1～3 个大块体出现，不把天空铺成碎石阵。

### 4-5～4-8：`thundercliff_storm_valley` 风暴峡谷

对应关卡：穿云长桥、雷羽哨塔、风暴回廊、天井祭台。

缩略图关键词：**高、侧压、风切**。两侧板岩高壁建立风谷压迫感，整体比高原更冷，但中央战斗区仍保持清楚、宽阔。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 灰紫风暴云带和两侧高耸远崖，夹入少量大块浮岩；中央保留至少 55% 的明亮天空开口 |
| `rear_v01.webp` | 两侧圆钝板岩、粗树根与短桥锚端，鼠尾草灌木贴近地表；不形成峡谷门或横梁 |
| `road_v01.webp` | 低饱和灰紫岩路，仅用 2～4 块宽大的风蚀浅色区表现磨损；不铺裂纹和碎石 |
| 专属前景 A | 紫灰层岩与鼠尾草宽叶组合，偏简单 |
| 专属前景 B | 粗风蚀树根、短断木板和少量草叶组合，偏复杂；不做连续木栅栏 |

“雷羽哨塔”和“天井祭台”不在循环长图中放独立高塔或祭坛，以免形成重复地标；题意由远处岩塔体量和旧铜小构件暗示。

### 4-9～4-12：`thundercliff_citadel` 苍雷要塞

对应关卡：浮城外庭、霆光阶梯、云宫门庭、苍雷天阙。

缩略图关键词：**块、塔、秩序**。这是三套地图中建筑感最强的一套，使用粗大的暖白石结构和少量旧铜、深青绿点色，与第三章沉沙古城的土黄低矮遗迹拉开差异。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 暖白高空要塞、宽塔楼和层叠城墙剪影；整体垂直但不使用密集尖塔 |
| `rear_v01.webp` | 两侧粗白石柱、矮墙、旧铜支架和断梁端部；中央通路完全开放 |
| `road_v01.webp` | 暖灰白石路，用 4～6 个大块铺装区概括材质；不画密集砖格、台阶透视或发光缝隙 |
| 专属前景 A | 暖白石残块与深青宽叶组合，偏简单 |
| 专属前景 B | 无符号旧铜导风构件与低石台组合，偏复杂；不画文字、徽记或雷电符号 |

“霆光阶梯”只通过远景建筑逐层抬高表达，不让地表变成正面台阶；“苍雷天阙”不使用发光核心或大型魔法门。

## 5. 构图和循环硬标准

- 背景工作母图为 `2172×724`；运行背景为 `1720×560`。
- 长图先按运行目标比例居中裁切，再等比缩放，不允许直接改变宽高比。
- 前景母图为 `576×384`；运行图为 `288×192 RGBA WebP`。
- 地表占母图高度约 68%～75%，上沿平均位于顶部以下约 25%～32%。
- 地表与后景交界必须是一条连续、明显的深灰棕粗圆描边；在母图上视觉粗度约 10～14 px，不能出现只有色块的缺线区段。
- 不画单点透视道路、正面桥面或台阶。中央约 70% 的主要行走带保持低对比，完整道路最多 3～4 处低频点缀。
- 后缘有效绘制高度约 78%～84%，中央约 45% 留口。峡谷岩壁、要塞柱墙只从两侧框景。
- 左右各 10% 为循环安全区，不放浮石、塔柱、桥头或铜构件等独特物件；两端地表高度、颜色和纹理节奏匹配。
- 前景主体占母图宽约 70%～82%、高约 72%～84%；底部自然搭接，上缘保留空隙、高低差和不对称轮廓。
- 前景继续采用简繁随机、水平翻转、缩放和约 `0.36～0.92` 屏的随机间隔，不制作连续前景长墙。
- 视差速度沿用现值：天空 `0.03×`、远景 `0.12×`、后缘 `0.32×`、地表 `1.00×`、前景 `1.22×`。

## 6. 禁止项

- 高饱和电蓝、荧光紫、满屏纯白云海或金色滤镜；
- 密集浮石、细小云纹、写实云雾、电影光束、闪电粒子和渐变噪点；
- 单点透视道路、正面桥面、正面台阶或横跨中央的悬桥；
- 重复高塔、祭坛、风铃、旗帜或其他会暴露循环的独特地标；
- 可读文字、雷电符号、宗教纹章、发光符文和魔法门；
- 密集砖缝、碎石、裂纹或写实尖锐岩层；
- 直接生成透明像素。

所有需要透明的图层继续使用纯 `#FF00FF` 色底生成，再由现有处理程序去底，避免抠图毛刺。
