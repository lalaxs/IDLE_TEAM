# 第六章「燃烧荒地」分层战斗场景美术需求确认稿

状态：**三套区域资源已生成、接入，并完成 `6-1`、`6-5`、`6-9` 代表关卡实机抽查**

第六章继续使用第一至第五章已经验证的横版分层地图工作流。视觉基准是当前游戏内 `1-1` 以及第三至第五章修正后的线条层级；旧章节合成背景只用于理解焦土、裂谷与荒城题材，不作为构图、细节密度或交互依据。现有 UI、交互、战斗逻辑和存档结构保持不变。

## 1. 章节定位

第六章从潮湿低洼的黑水湿地进入干燥高温的「燃烧荒地」。这里表现的是火灾、熔蚀和冶炼活动结束后仍留有余温的焦土，不是正在喷发的火山或持续燃烧的炼狱。战斗始终发生在宽阔、连续、可读的实体地面上：

1. `6-1`～`6-4`：低、横、开阔的焦土边原；
2. `6-5`～`6-8`：深、侧压、层叠的余烬裂谷；
3. `6-9`～`6-12`：厚重、垂直、秩序明确的烬岩荒城。

三套地图通过地貌体量、焦枯植被、少量冷却炉渣和无文字旧构件建立递进。关卡名称与敌人组合承担同一区域内的逐关差异；区域 Boss 连续复用四关，第 4 关只强化数值、随从与节奏，不为每关增加独立长图、地标、运行配置或存档字段。

## 2. 色彩与画风

- 全章天空：烟灰米 `#C8B9A8`、暖云灰 `#D6C9B9`。
- 通用轮廓：深炭褐 `#453B35`，保持圆润、连续，不使用纯黑。
- 焦土边原：灰棕焦土 `#927B66`、炭岩灰 `#69605A`、枯橄榄 `#77705A`。
- 余烬裂谷：暗赭红 `#79594D`、炉渣灰 `#625D59`、冷却岩棕 `#806957`。
- 烬岩荒城：灰烬石 `#988878`、黑铁灰 `#55514E`、旧墙棕 `#766253`。
- 小面积提亮色：低饱和余烬橙 `#AD744A`；只用于极少量岩层矿脉或磨损切面，不做发光体。

继续使用低饱和大色块和少量硬边暗面。每个主要形体最多一块宽暗面，不使用写实岩纹、密集泥裂、细碎煤渣、烟尘颗粒和小火星。

线宽层级沿用成熟标准：远侧中景约 `5～7 px`、后缘中景约 `6～8 px`、地表交界与前景约 `10～14 px`。远处的焦丘、裂谷和荒城轮廓仍须有低对比深色描边；烟带、云层和天空不描重边。不能把中景画成无边纯色块，也不能让中景与地表、前景等粗。

## 3. 资源范围

全章共制作 **10 张背景层和 8 个模块化前景**：

- 1 张全章共用天空；
- 3 套区域各 1 张远景、1 张后缘、1 张地表；
- 2 个全章通用前景；
- 3 套区域各 2 个专属前景。

运行时每个区域只加载当前四层背景和四个前景物件。沿用现有双图镜像循环、分层视差、简繁随机和间隔随机，不增加动态烟尘、热浪扭曲、熔岩模拟、逐关配置、存档字段或迁移模块。

## 4. 三套区域地图

### 6-1～6-4：`burning_scorched_frontier` 焦土边原

对应关卡：焦土关口、熔渣坡道、烬井营地、裂岩哨站。

缩略图关键词：**低、横、开阔**。这是全章最亮、地势最平缓的一套，以宽焦土和少量炭化植被建立入口，不画正在燃烧的荒原。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 两层低矮焦黑圆丘、稀疏枯树线和宽薄烟带；中央天际线开阔，不出现火山锥或烟柱 |
| `rear_v01.webp` | 两侧裂岩肩部、炭化粗树干和低枯灌木；形体断续，中央约 45% 保持开口，不形成连续焦木墙 |
| `road_v01.webp` | 宽阔灰棕焦土为主体，仅有 2～3 块宽缓炭灰磨损和极少量暗橙岩层切面；不画密集裂缝 |
| 专属前景 A | 炭化宽草与卷曲枯叶组合，偏简单；叶片粗大、数量克制、左右高低不对称 |
| 专属前景 B | 一段烧蚀树桩、圆润黑岩与少量焦草组合，偏复杂；树桩保持低矮，不像尖刺路障 |

“烬井营地”和“裂岩哨站”不直接画成重复水井或完整哨塔，只用低石圈、短木桩或少量旧构件暗示，避免固定地标暴露循环。

### 6-5～6-8：`burning_ember_rift` 余烬裂谷

对应关卡：热风荒路、黑铁岗哨、余烬裂谷、岩脉阶地。

缩略图关键词：**深、侧压、层叠**。两侧暗赭裂谷建立热压感，整体比焦土边原更冷更深；中央实体道路仍保持宽阔，角色不能站在熔岩或发光裂缝上。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 层叠暗赭红裂谷、低矮岩脊与横向烟雾带；中央保留明亮天空开口，不出现喷发口和流动熔岩河 |
| `rear_v01.webp` | 两侧炉渣岩肩、短黑铁桩和低矮冷却气孔岩；只表现钝圆孔洞，不画蒸汽、火焰或发光喷口 |
| `road_v01.webp` | 深灰岩路与 3～4 块宽大的冷却岩色区，仅保留少数宽矿脉；不画碎裂网、密集石阶和细小矿点 |
| 专属前景 A | 热蚀硬草、层岩与圆角黑石组合，偏简单；草叶受风倾斜但不做细刺 |
| 专属前景 B | 低矮炉渣岩口、粗岩根和少量枯草组合，偏复杂；孔口为暗色，不发光、不喷烟 |

“黑铁岗哨”不使用横跨战斗区的铁栅栏；黑铁只作为两侧短桩和局部结构切面出现。

### 6-9～6-12：`burning_ash_citadel` 烬岩荒城

对应关卡：燃烧回廊、烬心祭场、荒城门庭、燃石王座。

缩略图关键词：**厚重、垂直、秩序**。这是全章最深、结构感最强的一套，用焦黑城门肩部、断塔和低墙建立荒城边界，但中央战斗区保持完整，不画火焰宫殿。

| 层级 | 美术内容 |
|---|---|
| `distant_v01.webp` | 烟雾中的焦黑城门轮廓、两三座残缺断塔和低矮城墙；地标压在两侧，中央不出现完整王座或巨大门洞 |
| `rear_v01.webp` | 两侧灰烬矮墙、黑铁粗立柱和圆钝断石；结构断续，不横跨画面，不形成连续栏杆 |
| `road_v01.webp` | 灰烬石路与一条浅暖灰的宽行走带，使用 2～4 块大面积磨损色区；不画密集砖缝、符文、台阶或透视长廊 |
| 专属前景 A | 断裂素面石旗座、圆角碎石和少量焦草组合，偏简单；不挂旗帜，不出现文字与徽记 |
| 专属前景 B | 熄灭火盆、低矮断墙与黑岩组合，偏复杂；火盆内部为冷暗灰，不保留火苗、红光或烟雾 |

“祭场”“门庭”和“燃石王座”只由荒城结构体量暗示，不使用可读文字、宗教符号、发光王座或重复完整城门。

## 5. 构图和循环硬标准

- 背景工作母图为 `2172×724`；运行背景为 `1720×560`。
- 长图先按运行目标比例居中裁切，再等比缩放，不允许直接改变宽高比。
- 前景母图为 `576×384`；运行图为 `288×192 RGBA WebP`。
- 地表占母图高度约 68%～75%，上沿平均位于顶部以下约 25%～32%。暗橙岩脉只能作为少量地表色区，不能切断主要行走带。
- 地表与后景交界必须有连续的深炭褐粗圆描边；母图视觉粗度约 `10～14 px`，不能出现只有色块的缺线区段。
- 远侧中景的焦丘、裂谷、城门和断塔使用约 `5～7 px` 低对比描边；后缘树干、裂岩、立柱和矮墙使用约 `6～8 px` 描边。烟雾与云层不描重边。
- 中央约 70% 的主要行走带保持低对比；每条道路最多 3～4 处大而疏的炭灰磨损、岩脉或圆石点缀。
- 后缘有效绘制高度约 78%～84%，中央约 45% 留口。高形体从两侧进入，不能用整排等高岩柱或城墙填满上沿。
- 左右各 10% 为循环安全区，不放完整树桩、气孔岩、断塔、城门、火盆或旗座等独特物件；两端地表高度、颜色和节奏匹配。
- 前景主体占母图宽约 70%～82%、高约 72%～84%；底部自然搭接，上缘保留空隙、高低差和不对称轮廓。
- 前景继续采用简繁随机、水平翻转、缩放和约 `0.36～0.92` 屏的随机间隔；同一屏通常出现 1～2 片。
- 视差速度沿用现值：天空 `0.03×`、远景 `0.12×`、后缘 `0.32×`、地表 `1.00×`、前景 `1.22×`。

## 6. 禁止项

- 明亮流动熔岩、活跃火焰、火星粒子、发光裂缝、喷发火山或大面积高饱和红橙；
- 角色脚下熔岩河、横断战斗区的裂谷、沟壑、铁桥或断桥；
- 写实岩纹、密集泥裂、碎煤渣、细小矿点、烟尘噪点和热浪扭曲；
- 尖刺森林、写实焦尸、骨骸、血迹、怪物残肢或灾难废墟；
- 重复火山锥、完整城门、断塔、王座、火盆或其他会暴露循环的独特地标；
- 可读文字、符号、旗帜、徽记、发光符文、魔法火池或发光核心；
- 单点透视道路、正面长廊、密集石阶或把地表画成俯视地图；
- 直接生成透明像素。

所有需要透明的图层继续使用纯 `#FF00FF` 色底生成，再由现有处理程序去底，避免透明接缝毛刺。
