# 赤沙古道装备图标生成提示词

## 统一美术约束

以 `review/equipment-contact-sheet.png` 与 `references/equipment-hero-style-reference.png` 为统一风格参考。生成单件 2D 游戏装备图标，纯正面或轻微三分之四视角，主体占画布约 75%，轮廓清晰、重心稳定。采用与角色一致的深棕色粗圆描边、圆钝转角、3–5 种不透明平涂色和极少量大块内部分割；童话感、手绘感、简约易读。背景必须是完全均匀的纯品红色 `#ff00ff`，无阴影、无光晕、无粒子、无文字、无人、无人台、无边框、无透明玻璃、无细碎纹样、无写实材质。每次只生成一件物品。

## 武器

### `weapon_dune_crescent_sickle` — 流沙弯镰

一把短柄宽刃的月牙弯镰，镰刃圆钝厚实、形成强烈 C 形剪影，短柄缠一段赤红布。配色为旧金、深棕、陶土红，内部分割不超过三处。

### `weapon_sunshot_bow` — 烈阳短弓

一把矮而厚的反曲短弓，两端圆钝外翻，握把中央有一个简化太阳圆章。配色为暖木棕、旧金、沙白，弓弦只用一条粗而清晰的深棕线。

### `weapon_scarab_codex` — 圣甲虫秘典

一本厚实的圆角闭合秘典，正面中央只有一枚大型简化圣甲虫嵌饰，书脊与封面用大色块分开。配色为砂岩色、绿松石、靛蓝与深棕描边。

### `weapon_roadwarden_mace` — 古道战锤

一柄短木柄战锤，锤头是圆角方形的厚重砂岩块，正面嵌一块简化绿松石几何片。配色为砂灰、绿松石、木棕，剪影结实而不尖锐。

## 护甲

### `armor_dustwalker_mantle` — 踏尘披巾

一件悬空展示的宽肩旅行披巾，肩部形成扁宽弧形，正面垂下一条短赤红围巾。配色为沙白、陶土红、深棕，无人体、无衣架、无细小褶皱。

### `armor_sunscale_cuirass` — 烈日鳞甲

一件圆肩短胸甲，胸前仅有三片大型圆钝鳞片上下叠放，中央有一个小太阳圆章。配色为旧金、砂岩色、暗红，整体紧凑厚实。

### `armor_oasis_robe` — 绿洲长袍

一件悬空的宽下摆长袍，袖口简短圆润，腰部一条醒目的靛蓝宽腰带，领口用旧金小色块点缀。主色绿松石、靛蓝、旧金，无人体与透明薄纱。

### `armor_ruin_guard_pauldron` — 遗迹护肩

一件单侧不对称的大型遗迹护肩，主体像一块圆钝厚砂岩，表面只有一道大号绿松石嵌片与一条深棕绑带。配色砂灰、绿松石、深棕。

## 饰品

### `accessory_scarab_seal` — 圣甲虫印

一枚厚实圆形印章或护符，中央是大型简化圣甲虫图案，外圈宽而圆钝。配色绿松石、旧金、深棕，避免细小腿节和纹路。

### `accessory_sundial_disc` — 日轮盘

一个厚圆盘日晷，圆盘中心立起一块大型三角晷针，轮缘只有四个粗短刻度。配色沙白、旧金、陶土红，结构一眼可读。

### `accessory_sandglass` — 流沙计时瓶

一个腰部很窄的粗框沙漏，两端圆厚，内部用上下两块完全不透明的金砂色块表达流沙，中间不用透明玻璃。外框靛蓝与深棕，造型简洁。

### `accessory_caravan_bell` — 商旅驼铃

一枚圆钝厚实的青铜驼铃，钟口宽、顶部系一段短赤红绳，内部仅一个大号铃舌。配色旧金、陶土红、深棕，避免花纹与高光。
