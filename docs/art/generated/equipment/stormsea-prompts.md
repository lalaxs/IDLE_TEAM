# 苍雷云海装备图标生成提示词

## 统一美术约束

以 `review/equipment-contact-sheet.png` 与 `references/equipment-hero-style-reference.png` 为统一风格参考。生成单件 2D 游戏装备图标，纯正面或轻微三分之四视角，主体占画布约 75%，轮廓清晰、重心稳定。采用与角色一致的深棕色粗圆描边、圆钝转角、3–5 种不透明平涂色和极少量大块内部分割；童话感、手绘感、简约易读。苍雷云海统一使用云白、钴蓝、风暴紫、旧金四种区域色。背景必须是完全均匀的纯品红色 `#ff00ff`，无阴影、无光晕、无粒子、无文字、无人、无人台、无边框、无透明玻璃、无细碎纹样、无写实材质。每次只生成一件物品。

### `weapon_skyspire_staff` — 天穹杖

### `weapon_tempest_codex` — 苍雷秘典

一本厚实圆角闭合秘典，封面中央只有一枚大型云朵闪电印，书脊与封面用钴蓝、风暴紫、云白大色块分开，四角仅用旧金包角。
