## 1. 章节方向

全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。源图统一朝右，眼睛或眼窝均为无高光平涂；所有角色使用低饱和灰棕、灰紫、枯草灰绿和冷石灰，禁止荧光、符文、恐怖血肉与没有结构作用的简单条纹。

- 枯风荒丘：以风化异兽为主。形体来自掘地爪、风切耳冠、鸣腔甲与钝角，不做现实动物换色。
- 旧战坡地：使用完整的「残旗亡骨」Q 版类人阵营。保留约 2.2～2.5 头身、大圆头骨和短粗四肢，装备改为残矛、灰瓮、旧盾与素面残旗。
- 丘墓禁地：使用有完整生物骨架的石构守像。石板、断环与断拱必须成为关节、护甲或角冠，不把背景石头直接加眼睛。

## 3. 枯风荒丘设计卡

### E85 枯冠掘兽 / withercrest-burrower

- 主体：短身四足的幻想掘地兽，头部两侧的风切耳冠与额甲连成楔形，前爪宽而扁。
- 配色：风化灰棕主身、枯草灰绿耳冠、冷土灰腹面、旧金灰爪缘、深灰褐轮廓；眼睛无高光。
- 剪影：低伏、前宽后窄，鼻尖和前爪朝右。
- 区域联系：耳冠像被风压低的粗叶，背面只有一块丘土形护板。
- 禁止项：兔子、鼹鼠写实比例、长耳卖萌、毛发细丝、背部条纹、眼睛高光。

### E86 风尾跃怪 / windtail-hopper

- 主体：后腿发达的短身跃怪，头部只有一枚钝鼻角，尾端是一整块厚叶刃形重尾。
- 配色：枯草灰绿主身、灰紫背面、风化灰棕尾刃、冷土灰腹面、深灰褐轮廓；眼睛无高光。
- 剪影：前低后高、重心前压，跃进端朝右。
- 区域联系：尾刃与坡地宽叶枯植被同源，但具有明确肌肉连接。
- 禁止项：袋鼠、兔子、蜥蜴写实外形、细长尾、简单环纹、眼睛高光。

### E87 灰喙鸣兽 / graybeak-howler

- 主体：双足站立的鸟兽混合怪，短钝闭喙与胸前半月形鸣腔甲共同预示声压攻击；声压结构集中在胸甲，不让嘴部形成喇叭口。
- 配色：冷土灰躯干、灰紫背羽块、风化浅岩色鸣腔甲、枯草灰绿短冠、深灰褐轮廓；眼睛无高光。
- 剪影：短颈、圆胸、粗足，喙与视线明确朝右。
- 区域联系：鸣腔甲像风蚀岩的凹面，但不画裂纹网或石纹。
- 禁止项：喇叭口、圆形黑嘴洞、长管状嘴、普通乌鸦、鹫类写实羽毛、鼓胀肉囊、密集羽纹、张嘴尖牙、眼睛高光。

### E88 荒丘甲卫 / hillplate-warden

- 主体：宽体六足异兽，楔形头盾、两层错位肩甲和六枚短足组成稳定护卫轮廓。
- 配色：深风化灰棕主身、冷石灰肩甲、枯草灰绿关节、灰紫侧暗面、少量旧金灰甲缘、深灰褐轮廓；眼睛无高光。
- 剪影：矮宽、重心贴地，前部明显朝右。
- 战斗联系：双层肩甲预示周期护卫，冲撞时只压低身体，不展开额外部件。
- 禁止项：犀牛、甲虫写实比例、满背尖刺、甲面横条、密集铆钉、眼睛高光。

### B88 枯风角王 / witherhorn-king

- 主体：宽肩四足丘陵首领，两枚一长一短的钝角沿横向张开，颈肩覆盖一整块风压鬃甲，背部三块坡脊甲逐级收低。
- 配色：深灰棕主身、灰紫鬃甲、冷石灰角与前掌、枯草灰绿背甲、少量旧金灰转折、深灰褐轮廓；眼睛无高光。
- 剪影：前身高宽、后身收束，角尖和头部明确朝右。
- 标志技能：枯风横扫；低血时压低鬃甲连续冲阵两次。
- 禁止项：真实野牛或山羊、对称鹿角、毛发细丝、尖刺森林、简单鬃毛条纹、发光眼。

## 4. 旧战坡地设计卡

### E89 残矛骨卒 / broken-spear-bonesoldier

- 主体：Q 版亡骨近战兵，大圆头骨、短胸腔、短粗四肢，双手持一柄宽刃短残矛。
- 配色：风化旧骨灰、压实土褐护肩、残旗暮紫腰布、旧木灰棕矛柄、深灰褐轮廓；眼窝无高光。
- 复用来源：E53 沉舟骨卒；保留大头短身与圆钝骨块。
- 差异化改动：腐木短桨改为宽刃残矛，泥沼绿布改为暮紫腰布，站姿改成矛尖前探。
- 禁止项：写实成人骨架、细长腿、海盗配饰、血肉、密集骨节、发光眼窝。

### E90 灰瓮骨手 / ashurn-bonethrower

- 主体：Q 版亡骨投手，一臂后举宽口灰瓮，另一臂前伸，骨盆与脚掌保持短粗。
- 配色：旧骨灰主身、冷土灰瓮体、残旗暮紫腰布、旧木灰棕绑带、深灰褐轮廓；眼窝无高光。
- 复用来源：E54 沉泥骨手；保留后仰投掷姿态与大头比例。
- 差异化改动：泥罐改成扁宽灰瓮，增加单块土褐肩护，删除泥沼配色与备用罐。
- 禁止项：火焰瓶、药水光效、细长成人骨架、罐面文字或符号、弹药串、发光眼窝。

### E91 旧盾骨卫 / oldshield-boneguard

- 主体：Q 版亡骨盾卫，以圆角梯形旧盾护住前身，短腿和宽足甲形成下盘。
- 配色：旧骨灰主身、旧木灰棕盾体、残旗暮紫内衬、冷土灰足甲、旧金灰盾缘、深灰褐轮廓；眼窝无高光。
- 复用来源：E55 锚盾骨卫；保留宽盾防守姿态与短粗骨架。
- 差异化改动：船板盾改成无徽记土垒旧盾，锚脚甲改为宽圆石土足甲，肩部降低。
- 禁止项：圆形海盗盾、十字或纹章、密集铆钉、骑士长腿、尖刺盾、发光眼窝。

### E92 残旗骨尉 / tornbanner-bonewarden

- 主体：宽胸 Q 版亡骨精英，背负一面短而厚的素面残旗，右手持短柄方头战锤，肩部为两块圆钝土甲。
- 配色：旧骨灰主身、残旗暮紫旗面、压实土褐肩甲、旧木灰棕旗杆与锤柄、旧金灰锤面、深灰褐轮廓；眼窝无高光。
- 复用来源：E56 舟脊骨尉；保留前倾宽胸、横向体量和短腿。
- 差异化改动：船肋肩架改为短旗背架，长桨刃改为短柄战锤，重心由刺击改为侧压守阵。
- 禁止项：旗面徽记、长披风、细旗穗、军官头盔、密集重甲、发光眼窝。

### B92 旧战骨将 / battlefield-bone-general

- 主体：横向体量明显的 Q 版亡骨首领，左臂持半圆战盾，右臂持宽头短斧，背后厚重旗架只露出一段素面残旗。
- 配色：旧骨灰主身、深土褐胸甲和盾体、残旗暮紫内衬、冷土灰斧面与胫甲、旧金灰盾缘、深灰褐轮廓；眼窝无高光。
- 复用来源：B56 沉舟骨舵主；保留大头、宽臂、短腿和横向 Boss 体量。
- 差异化改动：舵刃改为半圆战盾与短斧组合，船首胸甲改为压土胸甲，加入厚背旗架并移除海上结构。
- 标志技能：旧盾压阵；低血时举旗号令一轮残矛骨卒并缩短横扫间隔。
- 禁止项：成人比例、长腿将军、旗面徽记、皇冠、海盗帽、骷髅装饰、发光眼窝。

## 5. 丘墓禁地设计卡

### E93 石趾伏兽 / stonetoe-crawler

- 主体：低伏四足的石构异兽，扁平面甲与躯体之间有清晰颈部，四足末端是宽盘形石趾。
- 配色：冷石灰主甲、丘土灰紫关节、风化浅岩面甲、深灰棕腹部、深灰褐轮廓；眼睛无高光。
- 剪影：长而低、前端朝右，背面仅两块互锁护板。
- 战斗联系：盘形石趾预示稳定近战，不使用漂浮或滚动移动。
- 禁止项：石头直接加眼睛、乌龟、鳄鱼写实比例、砖缝网、符文、发光核心。

### E94 环角疾兽 / ringhorn-runner

- 主体：窄身长后足的石构疾兽，头顶两段不闭合的弧形环角向后包围，前足短而有抓地趾。
- 配色：丘土灰紫主身、冷石灰环角、风化浅岩腿甲、深灰棕腹面、深灰褐轮廓；眼睛无高光。
- 剪影：前低后高，鼻尖和冲刺端朝右，断环不超过背部高度。
- 区域联系：环角取自断石环，但作为角根与头骨连接，不悬浮。
- 禁止项：鹿、羚羊或兔子写实外形、完整光环、漂浮部件、环面条纹、符文、眼睛高光。

### E95 墓门偶卫 / barrow-gate-sentinel

- 主体：短身双足石偶，左右肩板像低矮门肩，双前臂各是一块厚盾臂，头部嵌在肩线前方而不是石板上的人脸。
- 配色：冷石灰主甲、丘土灰紫关节、风化浅岩盾臂、深灰棕足部、少量旧金灰护板边、深灰褐轮廓；眼睛无高光。
- 剪影：方宽但不过高，双足完整踩地，攻击端朝右。
- 战斗联系：合拢盾臂时触发周期格挡，结构始终保持两臂可读。
- 禁止项：墓碑加眼睛、可读文字、十字、完整门洞、方块机器人、发光核心。

### E96 断拱石将 / brokenarch-stonewarden

- 主体：宽肩石构精英，半段断拱从背后连接两肩，柱形粗臂与宽石胫承担范围震击。
- 配色：深冷石灰主甲、丘土灰紫关节、风化浅岩断拱、深灰棕侧暗面、旧金灰小面积转折、深灰褐轮廓；眼睛无高光。
- 剪影：上宽下稳、短腿，断拱为开口结构，不形成完整圆环。
- 战斗联系：双臂同时砸地形成一次震击，断拱只作为肩背承力结构。
- 禁止项：完整门洞、巨人成人比例、细长柱腿、裂纹网、符文、发光眼。

### B96 墓环石王 / barrow-ring-stoneking

- 主体：横向宽大的丘墓守像，开口石环从后颈包围头肩，双层胸甲、巨型前臂和丘石后背构成四个主要识别点。
- 配色：深冷石灰主甲、丘土灰紫大关节、风化浅岩石环与胸甲、深灰棕腹面、少量旧金灰甲缘、深灰褐轮廓；眼睛无高光。
- 剪影：前臂最宽、头部前探朝右、短腿完全落地，石环不悬浮。
- 标志技能：墓环重击；低血时前臂与胸甲合拢进入短时固守，随后发动一次前压砸击。
- 禁止项：墓碑加脸、完整巨石门、漂浮石块、王冠、符文、裂纹网、发光核心或眼睛。
