# 广告VIP

活动页新增「广告VIP」，沿用资源栏、横向活动页签、浅色底板、深色立体卡片。顶部居中展示等级徽章与观看进度；VIP1至VIP6依次为青铜、白银、黄金、铂金、钻石、至尊，分别使用铜、银、金、铂绿、钻蓝、紫金配色，较高档位增加翼饰、宝石与冠饰。

「当前／下一档」页签分别展示对应等级的完整已解锁福利和每日、每周礼包。福利采用整行深色胶囊竖排列表，下一档用提升标记突出变化；下一档礼包只预览，当前档支持领取及补差额。未解锁VIP时，当前页显示基础福利与礼包锁定状态。满级只显示当前页签。徽章、档位页签与底部观看按钮固定，福利和礼包区域在小屏内滚动；切换档位保持页面、页签和内容视口高度不变，支持键盘左右切换。达到门槛立即升级并切回当前页展示新等级，500次满级后隐藏下一档。广告次数永久保留。

## 激励广告接入

`src/app/RewardedAds.ts` 提供 `setRewardedAdProvider`，平台适配器接收 `vip` 或 `shop` 展示位置，返回 `completed`、`cancelled` 或 `unavailable`。只有平台激励视频成功回调才能返回 `completed`；关闭、取消与失败不计次数、不发放广告奖励。并发点击只启动一次播放。

VIP入口每次成功观看累计1次；商店广告入口同时发放2次刷新并累计1次。商店可选择消耗1张广告券代替播放，发放相同刷新奖励但不增加观看次数。VIP满级后商店广告奖励仍可正常领取。

当前工程未配置广告SDK，默认提供者返回不可用，页面显示「广告暂不可用，请稍后再试」。正式平台启动时注册实际提供者；自动化用受控提供者验证完成、取消与失败路径，正式页面不提供模拟观看按钮。
