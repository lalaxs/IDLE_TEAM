## 1. 章节设计方向

第四章按云崖高原、风暴峡谷和苍雷要塞划分三个连续区域。全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。

- 云崖高原：低、横、开阔；灰薄荷、暖白岩与浅灰紫；形体强调宽耳、风帆、白岩甲壳和云冠。
- 风暴峡谷：高、侧压、风切；板岩紫灰、深灰蓝与鼠尾草绿；形体强调风孔、分叉尾、双区折叠翼面和厚重翼根。
- 苍雷要塞：块、塔、秩序；暖白石、深青绿、旧铜与冷灰影；形体强调塔冠、铜足、白壁甲壳和导风结构。
- 雷电只通过形体、冷暖配色和攻击职责暗示，不在角色身上绘制发光闪电、符号或粒子。
- 原始透明图统一朝右；眼睛为无高光深色平涂块；细节密度沿用第三章最终版本。

## 3. 云崖高原设计卡

### E37 风耳跳兽 / windear-hopper

- 主体：生活在高原风草间的小型跳兽，低伏圆身，后腿明显大于前腿。
- 配色：灰薄荷主身、暖白胸腹、浅灰紫耳内、深灰棕描边。
- 复用来源：E25 沙耳狐；保留低伏头身关系与四足连接。
- 差异化改动：两耳改为宽根后掠的风帆形，后足加宽，尾巴改为扁平云团形，并替换整套高原配色。
- 禁止项：直立兔耳、蓬松狐尾、写实毛发、长爪、眼睛高光。

### E38 云帆走兽 / cloudsail-strider

- 主体：短颈、梨形躯干的双足高原兽，背部只有一片向后弯曲的宽风帆。
- 配色：浅灰紫主身、暖白胸腹、灰薄荷背帆、深灰棕描边。
- 复用来源：无。
- 战斗联系：前倾姿态与粗长腿预示快速游击；背帆用于稳定侧风。
- 禁止项：鸟喙、羽毛、细腿、多片背鳍、发光风纹。

### E39 白岩甲虫 / whiterock-beetle

- 主体：低矮宽体甲虫，暖白圆壳由顶部受光面、冷灰紫侧暗面和壳缘转折组成；后侧嵌入一块楔形灰薄荷导风板。
- 配色：暖白岩壳、冷灰紫壳侧与腹部、灰薄荷嵌入板、深灰棕描边。
- 复用来源：E03 角盔甲虫；保留低身、粗腿和头壳连接。
- 差异化改动：原角盔压低为钝圆铲形额甲，背壳加宽为白岩圆壳，并把表面色带改成有厚度的嵌入式导风板。
- 禁止项：装饰条纹、环带、密集甲片、尖角、六条细腿、岩石裂纹、金属反光。

### E40 云脊角兽 / cloudridge-hornbeast

- 主体：矮壮四足角兽，一对宽角横向展开，肩部覆盖一整块暖白云脊。
- 配色：灰薄荷主身、暖白云脊、浅灰紫宽角、深灰棕描边。
- 复用来源：E16 雪角公羊；保留宽肩四足骨架。
- 差异化改动：螺旋角改为横展崖台形宽角，羊毛改为单块云脊肩甲，蹄部加宽。
- 禁止项：螺旋羊角、卷毛、金属护甲、尖刺、眼睛高光。

### B40 云冠狮鹫 / cloudcrown-griffin

- 主体：四足狮鹫，宽喙头、巨大前掌与两片折叠宽翼形成前重后轻的 Boss 剪影。
- 配色：灰薄荷躯干、暖白头胸与翼面、浅灰紫翼腹、深灰棕描边。
- 复用来源：无。
- 标志技能：云冠踏震；低血时连续短扑两次。
- 禁止项：展开飞行姿态、写实羽毛、鹰形细爪、金色王冠、复杂面纹、眼睛高光。

## 4. 风暴峡谷设计卡

### E41 风切岩兽 / windcut-rockbeast

- 主体：宽颚厚颈四足兽，颈侧两道风孔，背部三片圆脊改为统一后掠方向。
- 配色：深灰蓝主身、板岩紫灰背脊、鼠尾草绿下颚与风孔边、深灰棕描边。
- 复用来源：E31 裂风颚兽；保留厚颈蓄压结构与四足骨架。
- 差异化改动：背脊后掠、尾端变窄、风孔外缘加鼠尾草色，并替换峡谷配色。
- 禁止项：风囊、发光气流、尖牙、密集鳞片、碎岩纹。

### E42 雷尾迅兽 / thundertail-runner

- 主体：前低后高的紧凑四足迅兽，左侧粗尾在末端分成两片钝圆尾叶。
- 配色：板岩紫灰主身、深灰蓝背部、鼠尾草绿尾端、深灰棕描边。
- 复用来源：无。
- 战斗联系：长前伸姿态与分叉重尾表现急停转向和快速突进。
- 禁止项：真实猫犬头、细长身体、闪电符号、尖尾、写实毛发。

### E43 暴风绒蛾 / stormfleece-moth

- 主体：短圆躯干与厚绒颈，双翼各由前后两块宽翼面组成，翼面分界对应折叠转折。
- 配色：深灰蓝躯干、鼠尾草绿主翼面、板岩紫灰侧暗翼面与厚绒颈、深灰棕描边。
- 复用来源：E18 雪绒蜂；保留短圆虫体与双翼连接。
- 差异化改动：蜂翼改为宽蛾翼，头部触角缩短，胸部增加整块绒颈，去除蜂类腹节。
- 禁止项：透明翅、密集翅脉、蜂刺、细触角、发光粉尘。

### E44 风暴翼龙 / stormwing-drake

- 主体：厚胸双足翼龙，钝角冠向后延伸，一对重翼分成两块宽膜区。
- 配色：深灰蓝主身、板岩紫灰翼膜、鼠尾草绿胸带、深灰棕描边。
- 复用来源：无。
- 战斗联系：厚翼根与粗后足预示低空压制和落地击退。
- 禁止项：细长龙颈、密集翼骨、尖锐多角、写实鳞片、发光雷纹。

### B44 雷羽巨枭 / thunderplume-greatowl

- 主体：宽体巨枭，冠羽形成一整块风暴云轮廓，两翼半展，尾部为宽扇形。
- 配色：深灰蓝主身、板岩紫灰翼面、鼠尾草绿胸斑、暖云灰脸盘、深灰棕描边。
- 复用来源：B24 极光冠鸮；保留宽体、脸盘和粗爪骨架。
- 差异化改动：闭合翼改为半展巨翼，极光冠改为风暴冠羽，增加宽尾扇并替换峡谷配色。
- 标志技能：雷羽横扫；低血时缩短扫击间隔。
- 禁止项：极光色带、雪羽、写实细羽、发光眼、闪电图案。

## 5. 苍雷要塞设计卡

### E45 塔冠跃兽 / towercrest-pouncer

- 主体：紧凑四足跃兽，两枚宽根耳冠垂直但圆钝，像低矮塔肩而不是建筑。
- 配色：深青绿主身、暖白耳冠与胸腹、旧铜肩领护板、冷灰影、深灰棕描边。
- 复用来源：无。
- 战斗联系：宽前掌与前倾低头姿态表现短距离扑击。
- 禁止项：猫科长尾、真正塔楼、砖缝、金属头盔、尖耳、眼睛高光。

### E46 铜足疾鸟 / copperfoot-strider

- 主体：梨形短翼双足兽，粗胫与宽足形成主要速度识别，头部为钝圆短喙；两块旧铜胫甲包住小腿前侧并形成明确厚度。
- 配色：暖白主身、深青绿短翼、旧铜粗胫、冷灰影、深灰棕描边。
- 复用来源：E26 疾足沙鸵；保留梨形躯干、短颈与双足骨架。
- 差异化改动：尾羽缩成三片短尾，腿部增加带斜面转折的旧铜胫甲，头身改为要塞配色。
- 禁止项：细腿、长喙、写实羽毛、金属脚环、发光纹路。

### E47 白壁盾龟 / whitewall-tortoise

- 主体：低矮短颈盾龟，背部为暖白高壳，分成顶部受光面、两侧斜面和下缘暗面；高壳下方另接一整块深青绿下层护板。
- 配色：暖白高壳、深青绿下层护板、前后旧铜铰接块、冷灰肢体、深灰棕描边。
- 复用来源：E23 霜环龟；保留低体、短颈和粗足结构。
- 差异化改动：移除原壳面的雪环色带；背壳改为白壁高壳，深青色下移成具有独立轮廓的下层护板，并仅在前后连接点保留旧铜铰接块。
- 禁止项：装饰横带、环纹、连续金属包边、壳格、城砖、尖刺、金属铆钉、写实龟纹。

### E48 导风甲兽 / windguide-platebeast

- 主体：低宽四足兽，双层肩甲从头后向两侧展开，每侧肩甲嵌入一块带凹面阴影和斜切边的旧铜楔形导风板。
- 配色：深青绿主身、暖白双层肩甲、旧铜风槽、冷灰腹部、深灰棕描边。
- 复用来源：无。
- 战斗联系：宽前足负责击退；肩甲张开时为同伴提供短时加速。
- 禁止项：装饰条纹、连续色带、人形傀儡、建筑脸、密集甲片、砖缝、机械关节、发光核心。

### B48 苍雷守卫 / azure-thunder-warden

- 主体：四足守卫龙，暖白冠甲覆盖头肩，两片盾形折翼贴在身体两侧；旧铜只用于有厚度的翼前缘和翼根关节，短扇尾负责平衡后部轮廓。
- 配色：深青绿主身、暖白冠甲与翼面、旧铜翼缘、冷灰影、深灰棕描边。
- 复用来源：B04 森冠幼龙；保留四足龙体、折翼和粗尾骨架。
- 差异化改动：叶冠改为暖白整块冠甲，叶翼改为带结构翼缘的盾形折翼，尾端改为短扇形，并替换要塞配色。
- 标志技能：苍雷俯冲；低血时合拢折翼获得短时护盾。
- 禁止项：树叶、木纹、发光闪电、符文、金属铆钉、复杂龙鳞、眼睛高光。
