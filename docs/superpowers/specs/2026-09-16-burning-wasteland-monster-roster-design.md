## 1. 章节设计方向

第六章按焦土边原、余烬裂谷和烬岩荒城划分三个连续区域。全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。

- 焦土边原：低、横、开阔；灰棕焦土、炭岩灰与枯橄榄；形体强调铲形足、炭壳、焦根钝角和烧蚀大甲板。
- 余烬裂谷：深、侧压、层叠；暗赭红、炉渣灰与冷却岩棕；形体强调钝圆岩孔、分层炉渣板、宽矿脉切面和厚重翼根。
- 烬岩荒城：厚重、垂直、秩序；灰烬石、黑铁灰与旧墙棕；使用完整的「烬炉地精」类人阵营，以 2.0～2.2 头身的大头、短躯干、短粗四肢和宽手脚建立统一的 Q 版骨架，再用黑铁工具与灰烬石护具区分职业。
- 全章表现灾后余温，不使用活跃火焰、流动熔岩、火星、发光裂缝、发光核心或高饱和红橙。
- 色块边界必须对应甲板、壳面、岩层切面、骨架转折、衣片或装备接缝；禁止简单条纹与无结构的熔岩纹。
- 原始透明图统一朝右；眼睛使用无高光深色平涂块；母版后处理统一补充 18 px 深炭褐外描边。

## 3. 焦土边原设计卡

### E61 焦背掘兽 / charback-digger

- 主体：前重后低的短身掘地异兽，鼻端压成一块钝圆铲面，背部覆盖一整块向后收窄的烧蚀甲板。
- 配色：灰棕主身、炭岩灰背甲、枯橄榄前足、少量低饱和余烬橙切面、深炭褐描边；眼睛无高光。
- 复用来源：E57 雾苇潜兽；保留贴地四足与扁长头身。
- 差异化改动：舟形头甲改为铲形短吻，桨足改为宽掘足，背冠改为整块焦背甲，并替换焦土配色。
- 禁止项：写实獾、条纹、泥裂、火焰、发光裂纹、长爪。

### E62 炭鳍跃兽 / coalfin-hopper

- 主体：小型跃兽，身体呈短梨形，两片厚实的炭甲鳍从头后向后折叠，后足宽大而前足短小；炭甲鳍不是生物耳朵。
- 配色：枯橄榄主身、炭岩灰头鳍、暖灰腹面、深炭褐描边；眼睛无高光。
- 复用来源：E37 风耳跳兽；保留低伏圆身与跳跃后足。
- 差异化改动：风帆耳完全改为贴在头后的双层炭甲鳍，云尾改为短楔尾，躯干去除毛绒感并改为短梨形。
- 禁止项：写实兔、直立长耳、蓬松毛、火焰尾、头鳍条纹、眼睛高光。

### E63 渣壳钳虫 / slagcarapace-clawbug

- 主体：宽扁六足甲虫，背部是一大一小两块咬合的非对称炉渣壳，两枚前钳扁平如焦土铲。
- 配色：炉渣灰主壳、灰棕腹部、枯橄榄足部、暗橙壳缘切面、深炭褐描边；眼睛无高光。
- 复用来源：E51 浮壳钳虫；保留宽低六足与前钳连接。
- 差异化改动：浮木壳改为非对称炉渣板，钳尖压宽，足部收成短粗岩足。
- 禁止项：真实甲虫、对称条纹、密集裂纹、八条细腿、发光熔岩、金属反光。

### E64 枯根角兽 / charroot-hornbeast

- 主体：矮壮四足精英，两枚向前外展的粗钝焦根角从额侧生长，肩部覆盖一整块厚焦木甲。
- 配色：灰棕主身、炭岩灰肩甲、枯橄榄下腹、冷暖灰焦根角、少量暗橙磨损切面、深炭褐描边；眼睛无高光。
- 复用来源：E60 沼心角兽；保留宽肩四足、横角与宽蹄骨架。
- 差异化改动：苇角改为两段粗根角，额甲下移为焦木肩甲，前足显著加宽。
- 禁止项：鹿角枝杈、牛羊写实比例、火焰鬃毛、角面条纹、尖刺重甲、眼睛高光。

### B64 焦原楔兽 / scorched-wedgebeast

- 主体：前重后稳的四足巨兽，楔形额冠与巨大前掌组成冲压端，背部只有三块相互咬合的烧蚀大甲板，尾端压成短铲形。
- 配色：深灰棕主身、炭岩灰背甲、枯橄榄侧腹、暖灰额冠、少量低饱和暗橙甲缘切面、深炭褐描边；眼睛无高光。
- 复用来源：B52 黑水铠鳄；保留宽体短腿、巨大前掌和三块背甲的体量关系。
- 差异化改动：鳄形宽颚改为楔形额冠，长尾收短为铲尾，湿地背甲改为高低错落的烧蚀甲板，整体重心抬高到肩部。
- 标志技能：焦土冲压；低血时三块背甲闭合并获得短时减伤。
- 禁止项：写实犀牛或鳄鱼、外露獠牙、火焰、熔岩纹、密集尖刺、发光眼。

## 4. 余烬裂谷设计卡

### E65 孔背岩兽 / ventback-rockbeast

- 主体：低伏岩兽，肩背两侧各有一枚钝圆暗孔板，头部短而宽，后背向尾端抬高。
- 配色：炉渣灰、暗赭红、冷却岩棕与深炭褐；眼睛无高光。
- 复用来源：E41 风切岩兽；保留贴地四足与背脊连接，风孔改为无烟无光的冷暗岩孔。
- 禁止项：肿囊、喷火口、冒烟、亮橙洞口、密集孔洞、简单色带。

### E66 裂尾疾兽 / riftsplit-runner

- 主体：前低后高的疾行异兽，短粗尾端分成上下两片岩板，四足紧凑有力。
- 配色：暗赭主身、炉渣灰尾板、冷却岩棕腹面、深炭褐描边；眼睛无高光。
- 复用来源：E42 雷尾迅兽；保留低身与分叉尾，尾叶改成厚岩板并缩短口鼻。
- 禁止项：写实犬科、细长腿、闪电纹、火焰尾、条纹、眼睛高光。

### E67 冷渣甲蛾 / cooled-slag-moth

- 主体：短圆蛾兽，两片厚重宽翼像冷却炉渣板向后折叠，颈部覆盖一整块暖灰绒领。
- 配色：炉渣灰翼面、暗赭折翼暗面、冷却岩棕躯干、暖灰绒领、深炭褐描边；眼睛无高光。
- 复用来源：E43 暴风绒蛾；保留短圆虫体与两片宽翼连接。
- 禁止项：透明翼、翅脉网、发光粉尘、火星、规则翼纹、细触角。

### E68 炉脊锤兽 / furnaceback-mauler

- 主体：前倾双足精英，背部竖起一块厚高炉脊板，两条前臂末端像钝圆岩锤，肩部有一层横向承力岩板。
- 配色：暗赭主身、炉渣灰背板、冷却岩棕肩甲、暗橙磨损面、深炭褐描边；眼睛无高光。
- 复用来源：E44 风暴翼龙；保留前倾双足、厚翼根和粗尾连接；折翼收拢为炉脊板，前肢改为锤臂。
- 禁止项：龙翼展开、尖爪、火焰喷吐、岩浆裂纹、密集甲片、发光眼。

### B68 黯脉壳龙 / darkvein-shellback

- 主体：粗桩四足壳龙，头部覆盖宽岩冠，两片折叠壳翼贴住肩侧，背部只有三层相互错开的黯脉甲板。
- 配色：深炉渣灰主身、暗赭壳翼、冷却岩棕甲板、低饱和暗橙切面、深炭褐描边；眼睛无高光。
- 复用来源：B48 苍雷守卫；保留四足龙体、折叠翼面与粗尾，导风冠甲改为岩冠和壳翼。
- 标志技能：岩脉震击；低血时压低壳翼连续短扑两次。
- 禁止项：发光岩浆、骨翼、飞行姿态、密集龙鳞、尖刺冠、眼睛高光。

## 5. 烬岩荒城设计卡

### E69 烬炉地精 / ashforge-goblin

- 主体：约 2.05 头身的 Q 版地精近战兵，头部接近全高的一半，圆头短耳、极短躯干和短粗四肢，双手持一把不超过身体主轮廓的短柄灰烬石刃。
- 配色：低饱和橄榄灰皮肤、灰烬石护肩、旧墙棕衣片、黑铁灰武器、深炭褐描边；眼睛无高光。
- 复用来源：无；作为烬炉地精阵营的基础骨架母体。
- 禁止项：写实成人比例、大鼻瘤、尖牙外露、复杂皮甲、火焰纹章、眼睛高光。

### E70 灰刃斥候 / ashblade-scout

- 主体：约 2.0 头身的低伏地精斥候，短厚双耳向后收拢，躯干与腿部压短，两手各持一枚不外扩过远的短小铲形灰刃。
- 配色：橄榄灰皮肤、黑铁灰双刃、暗赭衣片、灰烬石护膝、深炭褐描边；眼睛无高光。
- 复用来源：E69 烬炉地精；保留大头长耳与短粗四肢，体型收窄并改为低伏冲刺姿态。
- 禁止项：盗贼兜帽、长匕首、密集皮带、骷髅徽记、写实肌肉、眼睛高光。

### E71 炉罐投手 / kilnjar-thrower

- 主体：约 2.1 头身的短身地精投手，一臂在头侧高举小型冷灰渣罐，另一条短臂向前平衡，腰侧只挂一枚备用小罐；动作轮廓不横向拉长。
- 配色：橄榄灰皮肤、冷灰渣罐、旧墙棕衣片、黑铁灰绑箍、深炭褐描边；眼睛无高光。
- 复用来源：E69 烬炉地精；保留基础头身比例，改为后仰姿态与单罐投掷职业结构。
- 禁止项：燃烧瓶、发光药水、弹药串、火把、密集绑带、眼睛高光。

### E72 黑铁监工 / blackiron-overseer

- 主体：约 2.1 头身的宽肩地精精英，横向宽于普通怪但不增加身高；两块黑铁肩架压低身形，双手持一柄短柄方头锤，腰部覆盖厚灰烬石护板。
- 配色：深橄榄灰皮肤、黑铁灰肩架与短锤、灰烬石护腰、旧墙棕内衬、深炭褐描边；眼睛无高光。
- 复用来源：E69 烬炉地精；保留大头短身，扩大肩宽与手脚，增加肩架、护腰和方头锤。
- 禁止项：全身重甲、尖刺肩、巨型长柄锤、火焰符文、军官披风、眼睛高光。

### B72 烬炉督军 / ashforge-warlord

- 主体：约 2.15 头身的宽体短腿地精首领，以横向体量而不是身高体现 Boss 级别；低矮灰烬石额冠、双层黑铁肩板和短柄宽炉锤组成首领剪影，头部仍接近全高的一半。
- 配色：深橄榄灰皮肤、黑铁灰肩甲与炉锤、灰烬石额冠、暗赭衣片、少量暗金磨损面、深炭褐描边；眼睛无高光。
- 复用来源：E69 烬炉地精；保留阵营脸部与头身比例，横向扩大胸肩、手脚与武器。
- 标志技能：炉锤震地；低血时号令一轮烬炉地精并缩短震地间隔。
- 禁止项：兽人成人比例、复杂王冠、长披风、密集铆钉、火焰锤头、发光眼。
