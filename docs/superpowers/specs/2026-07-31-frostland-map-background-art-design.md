# 霜原地图与战斗背景美术设计

- 版本：1.0
- 状态：已授权直接执行
- 日期：2026-07-31
- 适用范围：第二章「霜原」章节地图、2-1～2-12 战斗背景与区域前景遮挡层
- 视觉方向：延续第一章的厚描边童话风格
- 生产方式：内置 ImageGen 全景母图、色键前景与程序化审核

## 1. 范围与内容依据

项目中存在两份不同年代的第二章描述：

- 早期 Demo 与当前锁定预告使用「赤沙古道」；
- 最新已确认的 `2026-07-31-frostland-equipment-expansion-design.md` 将第二章定义为「霜原」，并明确按 12 个关卡推进。

本次以最新已确认的霜原规范为权威内容来源。由于用户要求直接完成后续章节设计，本轮不再进行逐图确认；同时不修改 `src/ui/AppShell.ts` 中的旧预告、不扩展运行时关卡数据，也不为尚未批准的第三章制作资产。

交付范围与第一章一致：

1. 12 张逐关战斗背景；
2. 1 张不含节点或文字的章节地图；
3. 3 张区域共用的透明前景遮挡层；
4. 提示词、生成清单、联系表、全章总览与验证报告。

## 2. 与第一章统一的视觉语言

### 2.1 继承项

- 暖黑或深褐色粗圆描边只用于近景物体和主要地标；
- 天空、远山、雪坡等大面积远景不使用完整黑色轮廓；
- 形状圆润、手绘、不规则，避免几何矢量感；
- 每个主要物体最多一块硬边暗面；
- 使用 6～9 个主要可见颜色，减少高频纹理；
- 中央约 58% 宽度保持低对比、连续、适合角色战斗；
- 所有图片不包含角色、怪物、UI、文字、数字、徽标或水印。

### 2.2 霜原差异

- 冰雪使用米白、灰蓝和浅青，不使用大面积纯白；
- 保留冻土棕、松木棕、深松绿与冷灰，避免整章只有蓝白；
- 冰体表现为不透明的大色块，不使用写实透明、折射或玻璃质感；
- 极光仅作为宽而柔和的青绿、浅紫色带，不使用粒子、光柱或电影式辉光；
- 雪面只保留少量大块阴影和圆润风纹，不绘制密集雪粒。

## 3. 章节视觉结构

采用三个区域、每区四关的结构：

| 关卡 | 区域 | 视觉任务 |
|---|---|---|
| 2-1～2-4 | 冻土前哨 `snowfield` | 从青丘进入开阔雪线，建立寒冷但可探索的第一印象 |
| 2-5～2-8 | 雪松幽林 `pinewood` | 加深阴影、加入雪松和冰溪，保持友好而非恐怖 |
| 2-9～2-12 | 极光遗迹 `aurora_ruins` | 使用冻石、冰脊和极光表现章节终点的古老感 |

三个区域共享低侧视战斗相机、连续地面基线与厚描边童话语言。色彩从暖灰冻土逐步转为深松绿，再转为冷灰蓝和克制的青紫极光。

## 4. 关卡设计

### 4.1 冻土前哨：2-1～2-4

主色为灰蓝天空、米白积雪、冻土棕、冷灰岩石与少量浅青冰面。地面保留一条暖灰褐色可行走区域，避免角色脚底融入雪地。

| 关卡 | 地标 |
|---|---|
| 2-1 雪线驿道 | 两侧低矮雪堆、无文字旧路桩和一束耐寒草 |
| 2-2 霜河浅滩 | 路侧冻结浅河、两三块圆润蓝冰和露出的冻土岸 |
| 2-3 风蚀雪坡 | 层叠圆雪坡、外露深褐冻土和被风压弯的矮灌木 |
| 2-4 断索冰桥 | 外侧旧木桥头、断裂粗绳和冰壳木桩，不让桥面跨过中央 |

### 4.2 雪松幽林：2-5～2-8

主色为灰青天空、深松绿、灰蓝阴影、雪白与木棕。树冠从两侧收拢，但中央道路始终比林下暗部更亮。

| 关卡 | 地标 |
|---|---|
| 2-5 雪松林口 | 两侧粗圆雪松、覆雪树冠和一个中空旧树桩 |
| 2-6 蓝冰溪谷 | 路侧窄冰溪、圆润蓝冰石与低矮冷雾 |
| 2-7 倒木迷径 | 两侧覆雪倒木、抬高树根与少量折断枝杈 |
| 2-8 寒灯营地 | 空白木牌、熄灭的厚重提灯和低矮圆石营地圈 |

### 4.3 极光遗迹：2-9～2-12

主色为冷灰天空、石蓝、暗蓝绿、冰白与少量青绿、浅紫。极光在远景上方形成章节识别，但不得干扰战斗特效。

| 关卡 | 地标 |
|---|---|
| 2-9 极光石原 | 两侧无符号立石、远处宽极光带与低矮冻岩 |
| 2-10 冻结石环 | 外侧低矮断裂石环、粗冰壳和四块空白界石 |
| 2-11 冰脊门廊 | 两侧不透明蓝灰冰脊形成门廊剪影，中央无横梁 |
| 2-12 霜心堡垒 | 巨大冻石内腔、远处克制青紫霜心与两侧旧堡垒肩墙 |

## 5. 章节地图

章节地图为不含 UI 的横向全景：

1. 左侧是开阔冻土前哨，雪线从第一章的灰绿地表自然过渡；
2. 中部进入深绿雪松林，路线发生一次明显转折；
3. 右侧成为蓝灰极光遗迹，终点是巨大冻石堡垒；
4. 一条宽阔浅灰蓝路线贯穿三个区域，预留 12 个 DOM 节点落点；
5. 地图细节密度比战斗背景低约 25%；
6. 不烘焙节点、圆圈、虚线、数字、锁、旗帜、标题或进度。

## 6. 透明前景遮挡层

每个区域制作一张与母图等尺寸的 RGBA PNG：

| 区域 | 遮挡内容 |
|---|---|
| 冻土前哨 | 两侧雪草、低雪堆、圆冻岩 |
| 雪松幽林 | 两侧松枝、粗树根、覆雪灌木 |
| 极光遗迹 | 两侧冻石、短冰脊、暗蓝绿耐寒叶簇 |

生产时在纯 `#ff00ff` 背景上生成色键源图，再使用本地色键工具输出透明图。前景可以触及底边与左右边，但必须满足：

- 两个顶部角 alpha 为 `0`；
- 中央横向 38%～62% 中 alpha 大于 `16` 的像素不超过 `0.1%`；
- 中央出现的少量像素只能位于最底部 36 px；
- 不得残留明显洋红边缘。

## 8. 审核与验收

- 13 张母图全部存在、可读取、尺寸一致且为 RGB PNG；
- 3 张透明前景全部存在、尺寸一致且为 RGBA PNG；
- 每个区域四张图共享天空、地平线、道路、相机高度、色板与光线；
- 三个区域在缩略图中可通过色彩和轮廓区分；
- 12 个关卡可通过地标辨认，不依赖文字；
- 中央战斗区无高对比大地标、红白横条或密集纹理；
- 冰雪保留冻土与松木色，不形成刺眼的整屏蓝白；
- 极光不形成技能特效、魔法阵或强光柱；
- 章节地图不含节点、圆圈、路径虚线、文字或其他 UI；
- 三张前景通过 alpha 范围、顶部透明角和中央畅通断言；
- 审核拼图中文标签清晰可读。

## 9. 接入边界

本轮只生产并验证美术资产，不覆盖 `public/assets/backgrounds/*.svg`，也不修改章节、存档和战斗数值。后续接入时：

- 不透明背景置于角色下方；
- 透明前景建议深度为 `300`；
- 技能与投射物保持 `350`～`400`；
- 跳字和胜利粒子保持 `500` 以上。
