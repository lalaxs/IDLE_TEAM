# 80 英雄专精技能重构

## 结论

当前 80 名英雄对应 40 个固定专精，每个专精有两名英雄。角色不能切换专精；同专精的两名英雄共享核心技能机制，以基础属性、伤害学派、伤害元素和美术表现形成角色差异。

战斗技能结构固定为：

- **专精主动技能**：自动施放，决定主要战斗循环；
- **专精被动技能**：围绕主动技能形成专精机制；
- **20 级通用被动**：从公共池任选一个，可以更换，用于补足构筑；
- **天赋与装备**：放大已有打法，不替代专精身份。

不再使用 8 套通用模板覆盖全部角色。新的技能数据应以 40 个固定 `specId` 为核心。

## 设计边界

### 专精主动技能

- 常规冷却控制在 5–8 秒；
- 单体输出通常为 180%–250% 攻击；
- 范围技能单目标系数较低，以命中数量换总收益；
- 坦克技能约为 130%–180% 伤害并附带生存效果；
- 治疗技能在攻击倍率与目标最大生命比例之间取高；
- 所有主动技能继续自动施放。

### 专精被动技能

被动必须改变角色的目标选择、资源循环、施法节奏、承伤方式或团队作用，不能只写成同质的固定增伤。被动效果应直接与本专精主动技能互动。

### 同专精双角色

同专精的两名英雄共享主动和被动机制，但技能造成的伤害沿用英雄自身的伤害学派与元素。例如同为戒律专精的角色可以分别表现为圣光与暗影赎罪，但仍使用同一套“伤害转治疗”机制。

## 20 级通用被动

通用被动保留自由选择与自由更换。选择后持续生效或在满足条件时自动触发，不消耗怒气、不占用行动，也不替代专精主动技能。

| 通用被动 | 定位 | 效果 |
|---|---|---|
| 铁壁意志 | 防护 | 常驻获得 8% 伤害减免 |
| 破阵余震 | 破阵 | 每第 3 次普攻命中使目标降低 12% 防御，持续 4 秒 |
| 陨星轨迹 | 先攻 | 对生命高于 70% 的敌人造成的普攻与专精主动技能伤害提高 15% |
| 圣域恩典 | 恢复 | 每次释放专精主动技能后，治疗生命比例最低的队友 4% 最大生命，受治疗加成影响；若有队友受到减速、破甲或易伤，优先选择并清除其状态 |
| 猎杀印记 | 增幅 | 造成暴击时使目标受到的所有伤害提高 8%，持续 4 秒 |
| 影袭本能 | 收割 | 对生命低于 35% 的敌人造成的普攻与专精主动技能伤害提高 20% |
| 霜寒追击 | 控制 | 每第 4 次普攻命中使目标减速 30%，持续 3 秒；目标已被减速时额外冻结 0.6 秒 |

通用被动不对职业或专精设置选择限制。由被动产生的伤害继承英雄自身的伤害学派、元素和相关装备增益。

## 实现结构

角色表增加明确的职业与专精字段：

```ts
interface HeroRosterEntry {
  id: HeroId;
  classId: ClassId;
  specId: SpecId;
  // 现有属性继续保留
}
```

`SpecId` 使用 40 个固定专精，而不是角色编号模板：

```text
death_knight_blood
death_knight_frost
death_knight_unholy
demon_hunter_havoc
...
warrior_arms
warrior_fury
warrior_protection
```

技能实现不应继续扩展为 40 个大型条件分支。需要抽象为少量可组合的战斗效果：直接伤害、多段、范围、弹射、持续伤害、持续治疗、标记与层数、护盾、属性状态、位移、召唤物、延迟承伤和伤害转治疗。每个专精技能通过效果组合与少量专属触发器构成。

通用被动继续使用角色存档中的 `chosenSkillId`。专精主动和被动由 `specId` 固定决定，存档中不提供专精切换字段。

## 验收结果

完成后应满足以下产品事实：

- 80 名英雄全部映射到 40 个固定专精；
- 同职业不同专精拥有不同主动、被动与战斗循环；
- 同专精两名英雄共享机制，但保留自身属性、元素和美术差异；
- 20 级通用被动仍可自由选择和更换；
- 通用被动不消耗怒气、不占用行动，也不会替代专精主动技能；
- UI 展示“职业 · 固定专精”，不出现切换专精入口。
