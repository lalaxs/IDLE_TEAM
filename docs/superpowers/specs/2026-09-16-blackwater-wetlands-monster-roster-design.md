## 1. 章节设计方向

第五章按黑水浅滩、沉舟泥沼和雾苇沼心划分三个连续区域。全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。

- 黑水浅滩：低、横、开阔；浅芦绿、湿泥棕与灰蓝水色；形体强调蹼足、宽钳、低伏甲壳和泥鳄背甲。
- 沉舟泥沼：湿、侧压、腐木；腐木棕、深苔绿与冷泥灰；使用一支完整的「沉舟亡骨」类人阵营，职业差异来自站姿、盾牌、投掷罐、船肋肩架与舵形武器。
- 沉舟亡骨统一采用约 `2.2～2.5` 头身的 Q 版比例：大圆头骨、短胸腔、短粗四肢与宽大手脚；精英和 Boss 通过横向体量与装备扩大等级差，不使用细长成人骨架。
- 雾苇沼心：深、静、秩序；深灰蓝绿、暗芦绿与旧石灰；形体强调苇冠、雾翼、苔甲和宽大的沼龙鳍冠。
- 全章不使用荧光毒液、发光眼、发光核心、恐怖腐烂或写实尸骸。亡骨敌人使用圆钝大块骨骼，不表现血肉残留。
- 原始透明图统一朝右；眼睛为无高光深色平涂块；所有色块边界均对应壳面、护板、翼膜、骨骼、木甲或身体转折，不使用简单装饰条纹。

## 3. 黑水浅滩设计卡

### E49 沼冠伏兽 / marshcrest-lurker

- 主体：蛙形但不写实的低伏湿地小兽，头背连成一块钝圆叶冠头甲，四足均为宽大的泥地蹼足。
- 配色：浅芦绿主身、灰蓝侧暗面、湿泥棕蹼足、干芦米黄下颚、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E06 苔盖跳蛙；保留圆身、低伏四足与短头身关系。
- 差异化改动：苔盖改为硬质叶冠头甲，前后足全部加宽为泥蹼，并替换黑水浅滩配色。
- 禁止项：蘑菇帽、圆斑、鼓胀喉囊、写实蛙皮、毒绿色、眼睛高光。

### E50 苇尾泥蜥 / reedtail-mudling

- 主体：低伸长体的湿地蜥形异兽，尾端不是普通尖尾，而是一整块厚实苇叶形重尾。
- 配色：灰蓝绿主身、浅芦绿背面、湿泥棕足部、干芦米黄腹面、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E22 岩脊雪蜥；保留贴地四足和长身骨架。
- 差异化改动：背部岩块移除，改成两块低矮芦脊；尾端加宽成结构明确的苇叶重尾，并替换湿地配色。
- 禁止项：真实蜥蜴花纹、背部条带、鱼鳍、细长蛇尾、密集鳞片、眼睛高光。

### E51 浮壳钳虫 / driftcarapace-clawbug

- 主体：宽而低的六足甲壳怪，背部为一块前高后低的浮木形硬壳，两枚前钳扁宽如泥铲。
- 配色：湿泥棕背壳、灰蓝腹部、浅芦绿壳侧暗面、旧木米黄钳尖、深泥炭灰绿描边；眼睛无高光。
- 复用来源：无。
- 战斗联系：硬壳预示减伤，扁钳用于护住正面；缩在壳下时不改变整体尺寸。
- 禁止项：真实螃蟹比例、八条细腿、壳面条纹、木纹刻线、贝壳花纹、眼睛高光。

### E52 黑水钳兽 / blackwater-clawbeast

- 主体：矮壮六足钳兽，两枚双层宽钳占据前部剪影，尾部拱起但收束为钝圆尾甲。
- 配色：深灰蓝绿主身、湿泥棕甲壳、浅芦绿钳侧板、冷泥灰腹部、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E27 沙钳蝎；保留低身、前钳与拱尾连接。
- 差异化改动：细蝎尾改为厚重钝圆尾甲，四条细足改为六枚短粗泥足，钳面增加有厚度的侧护板并替换湿地配色。
- 禁止项：毒针、粉色钳、细足、尖刺、壳面环带、发光毒液。

### B52 黑水铠鳄 / blackwater-armorgator

- 主体：宽体短腿的鳄形湿地巨兽，铲形宽颚与巨大前掌负责正面压迫，背部只有三块相互咬合的大甲板。
- 配色：深灰蓝绿主身、湿泥棕背甲、浅芦绿颈侧、冷泥灰腹面、干芦米黄颚端、深泥炭灰绿描边；眼睛无高光。
- 复用来源：无。
- 标志技能：黑水冲压；低血时背甲闭合并获得短时减伤。
- 禁止项：写实鳄鱼、满身小鳞片、锯齿背刺、尖牙外露、装饰条纹、发光眼。

## 4. 沉舟泥沼设计卡

### E53 沉舟骨卒 / wreckbone-deckhand

- 主体：前倾短身的亡骨近战兵，大头、宽肋骨与粗大手脚使用圆钝整块骨骼；双手持一根断裂短桨棍。
- 配色：旧骨灰主身、腐木棕短桨与护肩、深苔绿布片、冷泥灰侧暗面、深泥炭灰绿描边；眼窝为无高光深色平涂。
- 复用来源：无；作为沉舟亡骨阵营的基础骨架母体。
- 战斗联系：前倾重心与短桨棍说明直接近战，不附加多余装备。
- 禁止项：写实骷髅、血肉残留、尖牙、海盗帽、眼罩、骷髅徽记、发光眼窝。

### E54 沉泥骨手 / mirebone-thrower

- 主体：窄身短腿的亡骨投手，一臂后举泥罐，另一臂前伸保持平衡；大头与后仰姿态拉开轮廓，髋部只挂一枚备用泥罐。
- 配色：旧骨灰主身、冷泥灰泥罐、深苔绿腰布、腐木棕绑带、深泥炭灰绿描边；眼窝无高光。
- 复用来源：E53 沉舟骨卒；保留大块骨骼、头身比例和阵营配色。
- 差异化改动：体型收窄但保持短腿 Q 版比例，站姿后仰，短桨替换为投掷泥罐，并减少肩部结构。
- 禁止项：火焰瓶、发光药水、弹药串、写实骨节、海盗配饰、密集绑带。

### E55 锚盾骨卫 / anchorshield-boneguard

- 主体：下盘宽大的亡骨盾卫，右侧持一面由两块腐木拼合的宽盾，腿部护板呈钝圆锚脚结构。
- 配色：旧骨灰主身、腐木棕宽盾、深苔绿内衬、冷泥灰腿甲、深泥炭灰绿描边；眼窝无高光。
- 复用来源：E53 沉舟骨卒；保留大头、宽肋骨和粗手脚。
- 差异化改动：骨盆与小腿加宽，增加宽木盾和锚脚形腿甲，移除短桨并改为守势。
- 禁止项：真正船锚武器、圆形海盗盾、密集铆钉、骷髅徽记、重甲骑士、发光眼窝。

### E56 舟脊骨尉 / shiprib-bonewarden

- 主体：宽胸亡骨精英，两根粗弧船肋从肩后形成统一肩架，持一柄由断桨改成的宽头长刃。
- 配色：旧骨灰主身、腐木棕船肋与武器、深苔绿胸衬、冷泥灰肩暗面、干芦米黄刃口、深泥炭灰绿描边；眼窝无高光。
- 复用来源：E53 沉舟骨卒；保留阵营基础骨架和圆钝骨骼语言。
- 差异化改动：肩宽与胸腔明显放大，增加船肋肩架，武器拉长为宽头断桨刃，站姿改为侧压前进。
- 禁止项：肋骨尖刺、写实骨骼、密集护甲、长披风、海盗军官帽、发光符文。

### B56 沉舟骨舵主 / wreckbone-helmsman

- 主体：沉舟亡骨首领，半圆舵片与短柄连成一柄厚重舵刃，胸前覆盖一整块船首形腐木甲，粗骨臂与沉重木胫形成宽大 Boss 剪影。
- 配色：旧骨灰主身、深腐木棕胸甲与舵刃、深苔绿关节内衬、冷泥灰侧暗面、干芦米黄刃缘、深泥炭灰绿描边；眼窝无高光。
- 复用来源：E53 沉舟骨卒；保留阵营头部比例与骨骼材质。
- 差异化改动：整体体型加宽而非等比放大，新增船首胸甲、半圆舵刃和木胫；头部改为低矮腐木额冠，不使用海盗帽。
- 标志技能：舵刃横扫；低血时召集一轮沉舟骨卒并缩短横扫间隔。
- 禁止项：三角帽、眼罩、船长胡须、骷髅旗、钩手、写实恐怖头骨、发光眼窝。

## 5. 雾苇沼心设计卡

### E57 雾苇潜兽 / mistreed-stalker

- 主体：贴地四足的潜伏异兽，头部为扁舟形硬甲，前足分成两片厚实桨叶，背部只有一枚低矮苇冠。
- 配色：深灰蓝绿主身、暗芦绿背甲、旧石灰头甲、冷泥灰腹面、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E35 沉沙背兽；保留贴地四足、长头和宽背骨架。
- 差异化改动：沙丘背壳改为扁平暗芦背甲，前足改成分叶桨足，尾端缩短为厚实水舵形，并替换沼心配色。
- 禁止项：写实鳄鱼、沙丘背壳、简单背带色块、鱼尾、密集鳞片、眼睛高光。

### E58 雾幕绒蛾 / mistveil-moth

- 主体：短圆躯干的沼心蛾兽，两片宽翼像厚重雾幕向后折叠，颈部是一整块深苇色绒领。
- 配色：深灰蓝绿躯干、旧石灰主翼面、暗芦绿折翼暗面、冷泥灰绒领、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E43 暴风绒蛾；保留短圆虫体与宽翼连接。
- 差异化改动：四片折翼收成两片更长的雾幕翼，风暴绒颈改为深苇绒领，触角变为短钝双叶并替换沼心配色。
- 禁止项：透明翼、密集翅脉、发光粉尘、简单翼纹、细长触角、蜂刺。

### E59 苔甲盘兽 / mossplate-diskbeast

- 主体：低矮宽体四足异兽，背部由一大一小两块非对称苔甲咬合，前甲向下形成护肩，四足如粗盘根，头部为短钝面甲。
- 配色：暗芦绿双层苔甲、深灰蓝绿主身、旧石灰肩部承托板、冷泥灰腹面、深泥炭灰绿描边；眼睛无高光。
- 复用来源：无。
- 战斗联系：互锁苔甲预示周期减伤；四枚盘根足在支援同伴时压低身体。
- 禁止项：石头加眼睛、乌龟壳格、完整圆盘、蘑菇、简单同心圆、植物盆栽、发光核心。

### E60 沼心角兽 / marshheart-hornbeast

- 主体：宽肩四足精英，两枚横展苇角根部厚、末端钝，额头嵌入一块旧石灰额甲，四蹄宽大。
- 配色：深灰蓝绿主身、暗芦绿肩脊、旧石灰额甲、冷泥灰横角、深泥炭灰绿描边；眼睛无高光。
- 复用来源：E40 云脊角兽；保留宽肩、横展角和四足重心。
- 差异化改动：云肩脊改为后低前高的暗芦硬脊，崖角改为分层苇角，额部增加嵌入式旧石灰护甲并替换沼心配色。
- 禁止项：羊毛、鹿科细角、角面条纹、植物枝叶角、金属头盔、眼睛高光。

### B60 雾苇沼龙 / mistreed-marshdrake

- 主体：四足沼龙，头颈覆盖一整片宽苇鳍冠，两侧肩鳍厚而收拢，背部只有三块层叠苔甲，尾端为宽桨叶。
- 配色：深灰蓝绿主身、暗芦绿鳍冠与肩鳍、旧石灰苔甲、冷泥灰腹面、少量干芦米黄鳍缘、深泥炭灰绿描边；眼睛无高光。
- 复用来源：B48 苍雷守卫；保留四足龙体、粗尾和前重后稳的 Boss 骨架。
- 差异化改动：冠甲改为连续苇鳍冠，盾形折翼改为贴身肩鳍，白色甲片收成三块苔甲，尾端改为桨叶并替换沼心配色。
- 标志技能：雾潮压进；低血时压低肩鳍连续短扑两次。
- 禁止项：雷电结构、骨翼、展开飞行、密集龙鳞、发光雾气、植物树精脸、眼睛高光。
