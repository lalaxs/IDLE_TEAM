# 日常任务

活动新增「日常任务」页签，内部切换每日、每周。沿用浅色底板、深色立体卡片、金色选中铭牌和现有奖励图标。活动使用独立全屏页面，不透明浅色背景隔离战斗画面；签到、每日、每周共用固定的页面高度。左上角返回游戏，支持Esc逐层返回，背景控件不可交互。任务进度局部刷新，保留列表滚动位置；未完成任务提供前往入口。

## 周期与计数

每日按设备本地时间凌晨5点重置；每周按周一凌晨5点重置。签到、商店每日刷新次数与远征每日内容共用凌晨5点换日。同类型任务的成功操作同时累计每日和每周进度，周期独有任务仅在对应周期计数，领取状态独立。跨日不清除本周进度，跨周重置周任务。未领取奖励不结转、不补发。任务从接入后开始计数，不追溯历史操作。已有存档保留仍在列表中的任务进度，以及已领取的活跃度宝箱记录。

| 任务 | 每日目标 | 每周目标 | 计数口径 |
| --- | ---: | ---: | --- |
| 战斗胜利 | 10场 | 100场 | 重复通关也计入 |
| 讨伐宝箱 | 1次 | — | 每次有效开启计一次；随机宝石箱、材料箱不计 |
| 商店购买 | 1次 | — | 成功购买一项计一次；刷新和失败购买不计 |
| 炼金台合成 | 1次 | 10次 | 成功合成一件装备计一次；失败不计 |
| 升级英雄 | 1次 | 10次 | 主动消耗经验成功升一级计一次；战斗自动升级不计 |
| 远征领奖 | 1次 | 5次 | 完成返程并领取；提前召回不计 |
| 召唤英雄 | — | 5次 | 按实际召唤次数，五连计5次，重复英雄也计入 |

## 奖励

每日7项，每项奖励金币1,000、活跃度20，可选任务合计140活跃度；每周8项，每项奖励金币5,000、活跃度20，可选任务合计160活跃度。完成后手动领取才增加活跃度，进度条最多显示100。每日和每周均完成任意5项即可拿满阶段奖励；达到100后，其余任务仍可领取金币。每日可跳过2项，每周可跳过3项。

| 活跃度 | 每日奖励 | 每周奖励 |
| --- | --- | --- |
| 40 | 金币5,000、随机材料箱1 | 金币20,000、随机材料箱3 |
| 80 | 当前关卡60分钟基础经验、随机宝石箱2 | 当前关卡300分钟基础经验、随机宝石箱5 |
| 100 | 星石80、广告券1 | 星石400、广告券3 |

每项任务和每档奖励在对应周期只能领取一次。金币、星石和经验直接到账，宝箱、广告券进入材料背包。任务阶段奖励不发放进阶石。七天每日与一轮每周合计960星石。经验按领取时当前主线关卡计算，沿用基础产出公式：每分钟经验＝8＋关卡序号×4；每日乘60，每周乘300，不叠加离线能力加成。第10关每日2,880、每周14,400；第50关每日12,480、每周62,400。未领取时tips显示随当前关卡变化的具体数量；领取后保存实际发放的经验数值，切换关卡或重载存档后仍显示已领取数量，新周期重新计算。经验用于英雄升级。广告券的抵扣消费随正式激励广告接入；当前不新增观看广告任务，也不将测试广告入口计为有效观看。

## 操作反馈

活动入口、日常任务页签与每日／每周切换按钮，在有可领奖励时显示红点。每日与每周任务按可领取、未完成、已领取排序，同一状态内保持配置顺序；任务完成或领取后即时调整位置，保留任务列表滚动位置。每日／每周切换按钮等宽铺满一行，高34px，重置提示位于今日／本周活跃度右侧。进度条按比例标出40、80、100节点，节点下方的小气泡仅放置宝箱图标。可领取时，点击宝箱直接领取；未达成或已领取时，点击显示奖励说明 tips。tips 仅展示奖励名称、数量和状态，不包含领取按钮；点外部、再次点击宝箱或按Esc关闭。可领取用金色边框与红点标记，已领取用灰色宝箱与勾选标记。领取后更新库存、活跃度和红点，提示奖励已领取。

每日以战斗、收取与基础养成为主，每周另有召唤、英雄进阶和装备开孔。召唤仅列入每周，玩家可以跳过召唤、进阶、开孔，完成其余5项拿满活跃奖励。远征尚未解锁时，「前往」提示当前解锁条件。炼金台任务跳转装备合成，宝石任务跳转宝石合成，装备开孔跳转炼金台开孔模式；升级和进阶跳转英雄列表，召唤任务直接打开召唤页面。
