# 赤沙古道地图与战斗背景美术设计

- 版本：1.0
- 状态：已授权直接执行
- 日期：2026-08-01
- 适用范围：第三章「赤沙古道」章节地图、3-1～3-12 战斗背景与区域前景遮挡层
- 视觉方向：延续青丘边境与霜原的厚描边童话风格
- 生产方式：内置 ImageGen 全景母图、色键前景与程序化审核

## 1. 范围与章节定位

项目早期设计曾把「赤沙古道」作为第二章锁定预告；随后已确认并完成的第二章改为「霜原」。本轮将赤沙古道顺延为第三章，只生产美术资产，不改动现有章节数据、旧预告、存档结构或战斗数值。

交付范围与前两章一致：

1. 12 张逐关战斗背景；
2. 1 张不含节点、文字或 UI 的章节地图；
3. 3 张区域共用的透明前景遮挡层；
4. 提示词、生成清单、区域联系表、全章总览与验证报告。

## 2. 统一视觉语言

### 2.1 继承项

- 暖黑或深褐色粗圆描边只用于近景物体与主要地标；
- 天空、远沙丘和大面积山体不使用完整黑色轮廓；
- 使用圆润、手绘、不规则的大色块，避免几何矢量感；
- 每个主要物体最多一块硬边暗面，避免写实纹理与渐变噪点；
- 每张图使用 6～9 个主要可见颜色；
- 中央约 58% 宽度保持低对比、地面连续，供角色与敌人战斗；
- 所有图片不含角色、怪物、UI、文字、数字、徽标或水印。

### 2.2 赤沙古道差异

- 沙漠主色采用柔和赭黄、陶土红、灰粉、深褐和少量鼠尾草灰绿，避免整屏高饱和橙黄；
- 沙面使用大块圆润风纹，不绘制密集沙粒、写实扬尘或猛烈沙暴；
- 风蚀岩层保持厚实、圆钝和可读，不做尖锐写实峡谷；
- 古城使用灰米砂岩、暗青绿阴影与少量氧化铜色，装饰保持无文字、无符号；
- 不使用异域文字、宗教符号、骷髅、恐怖遗迹、魔法阵、传送门或文化刻板装饰。

## 3. 章节视觉结构

采用三个区域、每区四关的结构：

| 关卡 | 区域 | 视觉任务 |
|---|---|---|
| 3-1～3-4 | 赤沙驿道 `red_dunes` | 从冷色霜原过渡到温暖开阔地貌，建立长途商道感 |
| 3-5～3-8 | 风蚀峡谷 `wind_canyon` | 用陶土岩壁、干涸河谷与遮阳营地增加纵深和旅途痕迹 |
| 3-9～3-12 | 沉沙古城 `sunken_city` | 用半埋城墙、巨柱与王庭表现章节终点，保持友好童话感 |

色彩从开阔的赭黄与灰粉，推进到更深的陶土红，最后转为灰米砂岩、暗青绿与克制铜色。三个区域共享低侧视战斗相机、连续地面基线和中央安全区。

## 4. 关卡设计

### 4.1 赤沙驿道：3-1～3-4

主色为浅灰蓝天空、柔和赭黄、陶土红、灰粉与少量干草绿。近景地面保持偏灰的暖沙色，使角色轮廓不与背景混合。

| 关卡 | 地标 |
|---|---|
| 3-1 赤沙驿道 | 两侧低矮圆沙丘、无文字石质路桩和一束耐旱草 |
| 3-2 盐壳浅滩 | 路侧浅色盐壳洼地、圆润赭石与细窄干涸水痕 |
| 3-3 风刻沙坡 | 层叠圆沙坡、外露陶土岩层和被风压低的灌木 |
| 3-4 断轮商道 | 外侧断裂木轮、短车轴和半埋货箱，不让残骸进入中央 |

### 4.2 风蚀峡谷：3-5～3-8

主色为陶土红、深砖棕、灰紫阴影、灰蓝天空和鼠尾草灰绿。岩壁由两侧形成框景，但中央道路始终明亮、开阔。

| 关卡 | 地标 |
|---|---|
| 3-5 峡口石门 | 两侧圆钝砂岩柱形成自然石门，中央无横梁 |
| 3-6 回声旱谷 | 路侧干涸溪床、光滑圆石和少量浅色泥裂大块 |
| 3-7 盘岩小径 | 两侧卷曲层岩、抬高岩台和耐旱矮灌木 |
| 3-8 遮阳营地 | 外侧破旧布棚、无文字陶罐和熄灭火盆，中央无营具 |

### 4.3 沉沙古城：3-9～3-12

主色为灰米砂岩、暗青绿、深褐、氧化铜绿和少量暖铜。古城建筑以圆角大轮廓、半埋结构和克制装饰呈现，不使用可识别文字或符号。

| 关卡 | 地标 |
|---|---|
| 3-9 沉沙外城 | 两侧半埋无字城墙、残缺圆拱和低矮砂岩碎块 |
| 3-10 铜门集市 | 外侧氧化铜门板、空白布棚和收起的无字摊台 |
| 3-11 巨柱门廊 | 两侧高大圆角砂岩柱、断裂横梁与开放中央通路 |
| 3-12 赤砂王庭 | 远处半埋王庭、两侧肩墙和克制的青铜日辉色块，不使用发光符号 |

## 5. 章节地图

章节地图为不含 UI 的横向全景：

1. 左侧为开阔赤沙驿道，低沙丘和商道路桩形成起点；
2. 中部路线进入陶土色风蚀峡谷，发生一次明显转折；
3. 右侧出现半埋沉沙古城，终点为赤砂王庭；
4. 一条宽阔浅赭色道路贯穿三个区域，仅作为自然地貌，不预绘节点；
5. 地图细节密度比战斗背景低约 25%，为后续 12 个 DOM 节点预留空间；
6. 不烘焙节点、圆圈、椭圆台座、虚线、数字、锁、旗帜、标题或进度。

## 6. 透明前景遮挡层

每个区域制作一张与母图等尺寸的 RGBA PNG：

| 区域 | 遮挡内容 |
|---|---|
| 赤沙驿道 | 两侧耐旱草、低沙丘与暖色圆石 |
| 风蚀峡谷 | 两侧陶土岩块、干枝与灰绿灌木 |
| 沉沙古城 | 两侧砂岩碎块、暗青绿叶簇与不发光铜片 |

前景用纯 `#ff00ff` 色键源图生成，再通过本地工具输出透明图。前景可以触及底边与左右边，但必须满足：

- 两个顶部角 alpha 为 `0`；
- 中央横向 38%～62% 中 alpha 大于 `16` 的像素不超过 `0.1%`；
- 中央出现的少量非透明像素只能位于最底部 36 px；
- 不残留明显洋红边缘；
- 遮挡层位于敌人和角色上方时，仍保留中央主要交战区可见。

## 8. 审核与验收

- 13 张母图全部存在、可读取、尺寸一致且为 RGB PNG；
- 3 张透明前景全部存在、尺寸一致且为 RGBA PNG；
- 每个区域四张图共享天空、地平线、道路、相机高度、色板与光线；
- 三个区域在缩略图中可通过色彩、岩层和建筑轮廓区分；
- 12 个关卡可通过地标辨认，不依赖文字；
- 中央战斗区无高对比大地标、红白横条或密集纹理；
- 沙地不刺眼、不写实、不使用密集沙粒或沙暴；
- 古城没有文字、魔法阵、传送门、骷髅或宗教符号；
- 章节地图不含节点、圆圈、椭圆台座、虚线路径、文字或其他 UI；
- 三张前景通过 alpha 范围、顶部透明角和中央畅通断言；
- 审核拼图标签清晰可读。

## 9. 接入边界

本轮只生产并验证美术资产，不覆盖 `public/assets/backgrounds/*.svg`，也不修改章节、存档和战斗数值。后续接入时建议：

- 不透明背景置于角色下方；
- 透明前景深度设为 `300`；
- 技能与投射物保持 `350`～`400`；
- 跳字和胜利粒子保持 `500` 以上。
