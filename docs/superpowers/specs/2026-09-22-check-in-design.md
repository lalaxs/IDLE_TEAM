# 签到与随机宝箱

## 玩法

战斗区左上角增加「活动」按钮，与右侧战斗数据统计入口顶部对齐。全屏页面标题固定为「活动」，标题下方设置活动页签，目前开放「7日签到」。完成首次七次签到后的次日，该页签转为「每日签到」。有免费奖励可领取时显示红点；不自动打开页面。

每天按设备本地时间凌晨5点重置，与商店每日规则一致。每日手动领取一次；漏登不清零，不补签，不开放提前领取。首次累计七次完成「七日签到」，第七次领取当天保留完成态，下一天转为「每日签到」。每日签到按七次领取循环，不受自然周影响。新旧存档从第一次签到开始，不按账号创建日期补发。

基础奖励直接到账。进阶石、广告券和随机宝箱统一显示在「材料」背包，可用「宝箱与广告券」筛选。点击宝箱格子打开锚定的材料tips，查看内容与概率并点击「打开1个」；奖励直接放入材料背包，tips原位显示结果、更新库存并支持继续打开。最后一个用完后保留结果、禁用打开按钮，关闭tips后移除空宝箱格子。广告券tips展示用途和库存。奖励记录和余额一起保存。签到和宝箱均不设置广告翻倍。

## 新道具与美术

### 随机宝石箱（gem_box）

- 可堆叠、无期限、不占装备格、不可分解。
- 每次开启消耗1箱，获得1颗一级宝石。
- 现有12类宝石等概率，每类1/12（约8.33%）：攻击、暴伤、急速、技能、生命、防御、减伤、抗性、暴击、怒气、吸血、治疗。具体名称沿用现有材料配置。
- 显示完整奖励池和等概率说明；获得后展示宝石名称、数量与图标。
- 图标：蓝灰箱体、金色搭扣、红蓝紫宝石露出，暖棕厚描边、圆润轮廓、左上高光。沿用现有材料图标画风，256×256透明WebP。路径：`public/assets/resources/checkin_gem_box.webp`。

### 随机材料箱（material_box）

- 堆叠、使用和存放规则与宝石箱相同。
- 每次从四组中随机获得一组，各25%：开孔石×2、重置卷轴×3、熔炼触媒×2、套装刻印石×1。
- 奖励不含高阶宝石、套装精华或英雄。
- 图标：暖棕木箱、金属包角，露出重置卷轴、开孔石和熔炼触媒，轮廓与宝石箱统一，通过箱体和内容物共同区分。256×256透明WebP。路径：`public/assets/resources/checkin_material_box.webp`。

### 广告券（ad_ticket）

- 签到直接发放，存放于「材料」背包，可堆叠、无期限，不占装备格。存档以adTickets记录持有量，旧存档默认为0。
- 1张替代1次适用广告，领取相同奖励并消耗该入口次数；不计入实际广告观看累计。
- 玩家明确选择使用才扣除；不自动消耗。
- 图标：暖金票券、深青播放与跳过标记、暖棕厚描边和浅色高光；256×256透明WebP。路径：`public/assets/resources/ad_ticket.webp`。
- 当前版本支持发放、展示与存档；广告入口仍为测试占位，正式广告接入后实现抵扣消费。

### 进阶石（mat_ascend_stone）

- 复用现有进阶石配置与图标`public/assets/resources/mat_ascend_stone.webp`，签到直接发放到材料背包，用于英雄进阶，不新增素材。

## UI

- 入口复用现有礼物图标，按钮文字「活动」。左右工具入口共用同一定位行，中央关卡标题保持可见。
- 活动标题下方为独立的浅赭导航栏，页签最小尺寸为148×48，使用16px文字和活动图标。签到页签使用纸质日历徽章；选中项为深色立体铭牌、金色双层边框、暖金文字和底部菱角指示，未选中项为浅色底。页签单行排列，超出宽度时支持左右滑动，切换后保持所选页签可见。导航栏与内容区用分隔线区分；累计签到进度位于下方内容区，奖励卡片排列在进度行之后。活动页签配置包含标识、图标、名称和内容渲染，后续活动按同一入口增加页签。
- 签到页面使用奶油浅色底板、浅赭标题栏和浅色操作栏。待签到奖励卡片采用深炭灰立体底板和彩色奖励图标；已领取卡片使用暗灰底板、灰色奖励图标和较浅的投影，底部用绿色状态条及圆形勾选标记表示完成。今日奖励使用金边和暖黄状态条，第七日待领取时用细金边。领取按钮使用暖黄色。
- 六个普通奖励使用三列两行，第七次奖励横跨一行。显示奖励名称、数量、已领／待领状态，不依赖颜色表达状态。
- 深色奖励卡片使用厚描边、顶部内高光和底部实色投影形成厚度。日期使用独立圆角胶囊标签，标签有细边和轻微凸起；今日日期以金棕胶囊配暖黄文字突出。
- 底部仅一个领取按钮；领取后显示「今日已签到」。七日完成提示「凌晨5点开启每日签到」。活动采用全屏页面，左上角返回游戏，支持Esc，返回后焦点回到活动入口。
- 背包道具详情展示全部奖励池与概率，开启结果持续展示，最后一箱开启后保留所得结果。
- 仅签到进度、日期或宝箱状态变化时更新对应区域，不随战斗资源变化重建签到页面。

## 验收

同日重复点击只发一次；漏登续领；第七次当天不可领取循环首奖；第八次及第十四／十五次正确转换；刷新后进度、箱子与所得材料保留；旧存档获得默认空记录；宝箱无库存不可开启；十二类宝石和四组材料使用配置中的等概率池。

界面覆盖360×640、390×844、430×932、平板竖屏和桌面，确认入口对齐、短内容不产生多余滚动、窄屏无溢出、键盘关闭与焦点返回，以及游戏状态刷新不打断阅读位置。手机横屏沿用游戏的旋转提示，回到竖屏后可继续操作。
