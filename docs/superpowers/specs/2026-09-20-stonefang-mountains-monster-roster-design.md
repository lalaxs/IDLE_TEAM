## 1. 章节方向

全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。源图统一朝右，眼睛使用无高光平涂；角色采用冷灰花岗岩、灰赭山土、灰绿皮肤、旧木灰棕与少量低饱和矿青、灰晶紫。矿物色只形成宽面材质，不发光、不画碎晶网。

v02 保留 v01 已审核的物种、职业、朝向与主体轮廓，将岩石切面、肌肉暗面、衣褶和装备纹理合并为大色块。每个主要部位只允许一块宽暗面，内部线仅承担部件分界；120px 下不得出现碎面堆叠或材质噪点。

v04 保留 E107 的低伏四足风哨兽剪影；E108 使用熟悉的双足守卫结构，以单柄斜向石矛作为唯一大识别点，不再把门形建筑拼接到身体上。B108 继续保留双足、双巨盾臂与高背鳍，精英和 Boss 通过武器方向、肩宽和外轮廓明确分层。

- 牙峰山麓：花岗岩皮甲异兽。生物躯干与岩甲有清楚层级，不能把圆石直接加眼睛。
- 晶脉矿谷：完整的「灰岩矿团」Q 版兽人阵营。复用第七章兽人骨架，同时更换肤色、职业装备、姿态和肩部轮廓。
- 石牙天脊：迎风山门守像与山脊异兽。牙岩、门肩和风蚀翼板必须成为关节或护甲，不做漂浮石块。

类人槽位共 5 个，全部集中在晶脉矿谷，形成矿工、斥手、投手、监工与酋长的职业链。

## 3. 牙峰山麓设计卡

### E97 岩冠掘兽 / stonecrest-burrower

- 设计槽位：C09-R01-N1。
- 主体：低伏六足异兽，头顶是一整块前倾楔形岩冠，前足为宽扁掘爪，躯干覆盖两块互锁皮甲。
- 战斗定位：均衡近战。
- 视觉识别点：楔形岩冠、宽扁双掘爪。
- 配色：花岗岩灰甲面、灰赭褐躯干、高山草灰绿关节、深岩灰褐轮廓；眼睛无高光。
- 剪影：长而低，岩冠与双爪明确朝右，尾部短收。
- 复用来源：E85；保留低伏骨架和前爪重心。
- 差异化改动：枯草毛冠改为完整楔形岩冠，背部毛皮改为两块圆钝花岗岩皮甲，身体由灰紫棕改为山土灰赭。
- 禁止项：野猪、穿山甲、犀牛写实比例、尖刺背、碎裂纹网、眼睛高光。

### E98 钩尾跃怪 / hooktail-leaper

- 设计槽位：C09-R01-N2，紧凑型。
- 主体：窄身四足跃怪，后腿粗大，短尾末端是一枚与尾骨连接的圆钝石钩，额侧有两片后掠耳甲。
- 战斗定位：快攻突进。
- 视觉识别点：石钩短尾、后掠耳甲。
- 配色：灰绿皮肤、灰赭腿甲、冷石灰耳甲与尾钩、深岩灰褐轮廓；眼睛无高光。
- 剪影：前低后高，鼻端朝右，尾钩不高过背线。
- 复用来源：E86；保留紧凑跃击骨架和粗后腿。
- 差异化改动：长叶尾改为短石钩尾，软耳改为两片后掠岩甲，四足比例更紧凑。
- 禁止项：兔子、狐狸、羚羊、长飘尾、完整蝎钩、速度条纹、眼睛高光。

### E99 震颚鸣兽 / quakejaw-caller

- 设计槽位：C09-R01-N3。
- 主体：短身三足异兽，头部两侧各有一块圆角颚板，闭合时像钝牙岩，张合产生短距震波；嘴部保持短而闭合。
- 战斗定位：中距震波。
- 视觉识别点：成对颚板、三点宽足。
- 配色：深板岩灰躯干、牙白岩颚板、灰晶紫侧暗面、灰赭足部、深岩灰褐轮廓；眼睛无高光。
- 剪影：头大身短，颚板朝右，三只脚完整落地。
- 区域联系：颚板借用圆钝牙岩节奏，但与头骨、颈部和躯干完整连接。
- 禁止项：巨大肿囊、大张嘴、音响喇叭、青蛙、石头加脸、发光口腔、简单横条。

### E100 岩肩护兽 / rockshoulder-guard

- 设计槽位：C09-R01-E1。
- 主体：矮宽四足精英，前肩覆盖两块向外展开的厚岩肩甲，背部是三块互锁圆甲，头部从肩甲之间前探。
- 战斗定位：周期护卫。
- 视觉识别点：双层岩肩甲、三块互锁背甲、宽前掌。
- 配色：深花岗岩灰主甲、灰赭褐躯干、灰绿关节、牙白岩甲缘、深岩灰褐轮廓；眼睛无高光。
- 剪影：前宽后窄、重心贴地，头和前掌朝右。
- 复用来源：E88；保留矮宽四足体态。
- 差异化改动：丘墓叠甲改为外展双肩甲与互锁背甲，前足加宽，去除丘墓灰紫主色。
- 禁止项：甲虫、犀牛、满背尖刺、横向甲纹、铆钉网、眼睛高光。

### B100 裂峰牙王 / splitpeak-fangking

- 设计槽位：C09-R01-B1。
- 主体：宽肩四足山麓首领，前额只有一枚分叉但圆钝的裂峰牙冠，肩背是一整块斜坡形花岗岩甲，两只前臂厚重外展。
- 战斗定位：横向冲阵。
- 视觉识别点：分叉牙冠、整块斜坡肩甲、厚重前臂、短而稳的后躯。
- 配色：深花岗岩灰甲面、灰赭褐躯干、灰晶紫颈侧暗面、牙白岩牙冠与前掌、深岩灰褐轮廓；眼睛无高光。
- 剪影：前身宽高、后身收束，牙冠和脸明确朝右。
- 复用来源：B88；保留前重后收的 Boss 骨架。
- 差异化改动：双横角改为单枚分叉牙冠，鬃甲改为整块坡形岩肩甲，四肢由毛皮结构改为岩甲前臂。
- 标志技能：裂峰冲阵；低血时先合拢前臂固守，再发动一次贯穿冲击。
- 禁止项：野牛、山羊、鹿角、王冠、尖峰森林、甲面条纹、发光眼。

## 4. 晶脉矿谷设计卡

### E101 灰岩矿徒 / graystone-miner

- 设计槽位：C09-R02-N1。
- 主体：Q 版兽人矿工，约 2.3 头身，大头短颈、宽手短腿，双手握一把宽头短镐。
- 战斗定位：均衡近战。
- 视觉识别点：宽头短镐、单片低肩护。
- 配色：低饱和灰绿皮肤、旧木灰棕衣甲、深板岩灰短镐、少量矿青腰布、深岩灰褐轮廓；眼睛无高光。
- 剪影：低伏前倾、肩窄于头宽，镐头朝右。
- 复用来源：E81；保留大头短身与前倾站姿。
- 差异化改动：海岸短刃改为宽头短镐，蓝灰皮肤改为灰绿，潮甲改为旧木与矿布组合。
- 禁止项：成人比例、写实肌肉、矿工帽、密集工具、尖牙特写、复杂脸纹、眼睛高光。

### E102 晶镐斥手 / crystalpick-skirmisher

- 设计槽位：C09-R02-N2。
- 主体：Q 版轻装兽人斥手，身体前倾，右手持单刃短镐，左臂后摆，背部只有一条宽工具带。
- 战斗定位：快速游击。
- 视觉识别点：单刃短镐、后掠长耳。
- 配色：灰绿皮肤、冷灰矿布、旧木灰棕护腕、低饱和灰晶紫镐刃、深岩灰褐轮廓；眼睛无高光。
- 剪影：窄肩、短腿、前探姿态，武器端朝右。
- 复用来源：E82；保留轻装低伏比例。
- 差异化改动：盐刃改为单刃矿镐，肩部缩窄，脚步改为前后错开的疾跑姿态。
- 禁止项：匕首刺客、兜帽、双持武器、长腿、发光晶刃、复杂皮带、眼睛高光。

### E103 矿钉掷手 / piton-thrower

- 设计槽位：C09-R02-N3。
- 主体：Q 版兽人投手，右手举一枚宽头钝矿钉，左臂佩一块短护臂，腰侧只有两枚大块备用矿钉。
- 战斗定位：远程投掷。
- 视觉识别点：宽头矿钉、短护臂。
- 配色：灰绿皮肤、深板岩灰矿钉、灰赭布甲、低饱和矿青护臂、深岩灰褐轮廓；眼睛无高光。
- 剪影：身体略后仰，投掷手朝右上，短腿仍完整落地。
- 复用来源：E83；保留单臂投掷和大头比例。
- 差异化改动：礁盘改为两端宽钝的矿钉，潮甲改为矿谷布甲，投掷姿态更直立。
- 禁止项：飞刀、炸弹、药瓶、整串弹药、写实肌肉、发光矿石、眼睛高光。

### E104 石肩监工 / stone-shoulder-overseer

- 设计槽位：C09-R02-E1。
- 主体：Q 版宽肩兽人精英，两块圆钝石肩甲构成横向轮廓，双手持短柄方头矿锤，胸前只有一块宽护板。
- 战斗定位：范围压制。
- 视觉识别点：双石肩甲、方头矿锤、宽胸护板。
- 配色：深灰绿皮肤、花岗岩灰肩甲、旧木灰棕柄、灰晶紫胸板、少量矿青腰布、深岩灰褐轮廓；眼睛无高光。
- 剪影：上宽下短，锤头和视线朝右。
- 复用来源：E84；保留宽肩短腿和单手重武器骨架。
- 差异化改动：潮垒护甲改为双石肩甲与单块矿谷胸板，武器改为短柄方头矿锤，姿态由守卫改为前压。
- 禁止项：重甲骑士、巨型长柄锤、尖刺肩、密集铆钉、矿场徽记、发光眼。

### B104 晶脉酋长 / crystal-vein-chief

- 设计槽位：C09-R02-B1。
- 主体：横向宽大的 Q 版兽人矿团首领，右手持双面宽头岩锤，左臂是一块厚重矿壁盾，背部只有两枚粗短不发光晶柱。
- 战斗定位：重锤震击。
- 视觉识别点：双面岩锤、矿壁盾、双短晶柱、宽厚胸甲。
- 配色：深灰绿皮肤、深板岩灰甲面、旧木灰棕握柄、低饱和灰晶紫晶柱、矿青小面积护板、深岩灰褐轮廓；眼睛无高光。
- 剪影：头大肩宽、短腿、锤与脸朝右，盾面不遮挡头部。
- 复用来源：B84；保留横向 Boss 体量和短腿比例。
- 差异化改动：潮垒重锤与海岸甲改为矿壁盾、双面岩锤和双短晶柱，皮肤由蓝灰改为灰绿。
- 标志技能：晶脉震击；低血时盾面合拢短时减伤，随后连续砸击两次。
- 禁止项：成人兽人比例、复刻第三方兽人、皇冠、巨型獠牙、尖刺重甲、发光水晶、密集脸纹、眼睛高光。

## 5. 石牙天脊设计卡

### E105 锁趾伏兽 / locktoe-clinger

- 设计槽位：C09-R03-N1。
- 主体：长而低的山脊异兽，四足末端各有两枚扣岩宽趾，背部只有一块前低后高的风蚀甲，头部与颈部清楚分开。
- 战斗定位：稳定前排。
- 视觉识别点：双瓣扣岩趾、斜坡形背甲。
- 配色：银岩灰甲面、冷蓝岩灰躯干、灰赭关节、牙白岩足趾、深岩灰褐轮廓；眼睛无高光。
- 剪影：低长贴地、四足分明，头部朝右。
- 复用来源：E93；保留低伏四足与宽足结构。
- 差异化改动：盘形石趾改为双瓣扣岩趾，双背板合并为一块斜坡风蚀甲，身体更窄长。
- 禁止项：鳄鱼、乌龟、蜥蜴写实比例、石块加脸、裂纹网、发光核心。

### E106 断翼疾怪 / brokenwing-runner

- 设计槽位：C09-R03-N2，紧凑型。
- 主体：窄身双足疾怪，两块短而厚的断翼板从肩胛向后收束，只用于稳定冲刺，不具备飞行结构；前臂短而有宽爪。
- 战斗定位：快速切入。
- 视觉识别点：成对断翼板、长而粗的后腿。
- 配色：冷蓝岩灰躯干、银岩灰翼板、灰晶紫侧暗面、牙白岩爪端、深岩灰褐轮廓；眼睛无高光。
- 剪影：前低后高、双足着地，脸和攻击端朝右。
- 复用来源：E94；保留紧凑疾跑骨架。
- 差异化改动：断环角改为与肩胛连接的双断翼板，四足改成短臂双足，强调奔跑而非跳跃。
- 禁止项：鸟、翼龙、蝙蝠写实比例、完整翅膀、飞行姿态、羽毛细丝、眼睛高光。

### E107 峰喙哨怪 / peakbeak-sentry

- 设计槽位：C09-R03-N3。
- 主体：低伏四足风哨兽，小型楔头覆盖牙白岩面甲，肩背长出一片向后倾斜并与躯干相连的宽风板。
- 战斗定位：远距风压。
- 视觉识别点：楔形面甲、单片背风板、短尾与四足低重心。
- 配色：冷蓝岩灰躯干、牙白岩面甲与爪端、灰晶紫背风板、深岩灰褐轮廓；眼睛无高光。

### E108 脊门矛卫 / ridge-spear-guard

- 设计槽位：C09-R03-E1。
- 主体：Q 版双足石像守卫，角盔、小型胸甲、正常比例双臂与短粗腿构成可信守卫骨架；双手只持一柄粗短石矛，矛尖朝右。
- 战斗定位：拦截击退。
- 视觉识别点：单柄斜向石矛、角盔、紧凑双足守卫体型。
- 配色：深冷蓝岩灰躯干、牙白岩头盔、胸甲与矛尖、灰晶紫关节带、深岩灰褐轮廓；眼睛无高光。
- 剪影：肩宽收窄，双脚完整踩地，石矛形成由左下至右上的单一斜线。
- 复用来源：无；使用本章低细节守像材质与描边基准独立设计。
- 差异化改动：不使用门洞、背鳍或盾臂；与 B108 的宽体双盾轮廓分离，以单柄斜向武器承担精英识别。
- 禁止项：建筑拼接身体、四足兽体、手持盾、椭圆盾臂、独立高背鳍、巨型拳臂、成人骑士比例、符文、裂纹网、发光核心。

### B108 天脊岩主 / highridge-stone-lord

- 设计槽位：C09-R03-B1。
- 主体：横向宽大的双足山脊守像，头顶是一枚前倾钝牙冠，肩后两块高低不同的山门肩板保持开口，巨型盾臂与宽胸甲构成前压体量。
- 战斗定位：前压重击。
- 视觉识别点：单枚钝牙冠、不对称门肩、巨型盾臂、双层宽胸甲。
- 配色：深冷蓝岩灰主甲、银岩灰门肩与胸甲、灰晶紫大关节、牙白岩牙冠、深岩灰褐轮廓；眼睛无高光。
- 剪影：肩部最宽、短腿稳固，牙冠、头部和前臂明确朝右。
- 复用来源：B96；保留横向 Boss 体量和巨型前臂。
- 差异化改动：丘墓开口石环改为高低不对称的双门肩，四足前压改为双足站立，头顶增加单枚钝牙冠并减去丘墓背甲。
- 标志技能：天脊压阵；低血时双盾臂合拢固守，随后向前连续发动两次重击。
- 禁止项：完整巨门、雕像人脸、皇冠、漂浮石块、尖刺森林、符文、发光核心或眼睛。
