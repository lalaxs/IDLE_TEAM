## 1. 章节设计方向

第七章按盐雾礁滩、浪蚀岩岸和潮蚀遗垒划分三个连续区域。全章使用 9 个普通怪、3 个精英和 3 个 Boss，共 15 个槽位。

- 盐雾礁滩：低、横、开阔；湿沙灰棕、浅礁灰和柔和海蓝；使用盐壳甲板、宽鳍、铲形盐喙和圆钝礁盾建立浅海异兽生态。
- 浪蚀岩岸：高低错落、侧压、冷峻；冷岩灰、深潮蓝灰和灰绿；使用海蚀颚板、裂鳍、折叠潮幕翼和厚重岸脊建立更强的岩壳威胁。
- 潮蚀遗垒：深、静、秩序；深蓝灰石、盐壳灰和氧化铜绿；使用完整的「潮垒兽人」阵营，以 2.1～2.3 头身、宽方头、短耳、小圆钝下獠牙和短粗四肢建立统一骨架，再以盐石工具和旧铜护具区分职业。
- 全章处于水下环境，但敌人必须站在连续实体海床上；不使用漂浮姿态、鱼尾代替双脚、气泡串、浪花、发光珍珠或透明水体特效。
- 色块边界必须对应盐壳甲板、礁石切面、鳍板、甲壳转折、衣片或装备接缝；禁止简单条纹、密集贝壳纹和无结构水波纹。
- 原始透明图统一朝右；眼睛使用无高光深色平涂块；母版后处理统一补充 18 px 深海褐灰外描边。

## 3. 盐雾礁滩设计卡

### E73 盐甲钳兽 / saltplate-clawbeast

- 主体：宽扁六足礁壳兽，背部是一大一小两块咬合的扇形盐壳，两只前钳一宽一窄，宽钳像浅滩铲板。
- 配色：浅礁灰主壳、湿沙灰棕腹部、柔和海蓝关节、旧铜灰绿壳缘、深海褐灰描边；眼睛无高光。
- 复用来源：E51 浮壳钳虫；保留宽低六足与前钳连接。
- 差异化改动：浮木壳改为扇形盐礁甲板，双钳改为非对称铲钳，足部压成短宽礁足。
- 禁止项：写实螃蟹、对称条纹、密集藤壶、细长腿、珍珠、眼睛高光。

### E74 潮鳍跃兽 / tidefin-hopper

- 主体：低伏短身跃兽，两片厚实后掠潮鳍贴住头后，后足宽大如蹬板，前足短小并靠近胸口。
- 配色：柔和海蓝主身、浅礁灰鳍板、湿沙灰棕腹面、旧铜灰绿鳍根、深海褐灰描边；眼睛无高光。
- 复用来源：E50 苇尾泥蜥；保留贴地短身、宽后足与低头冲刺姿态。
- 差异化改动：苇尾改为短分鳍尾，头后增加双层潮鳍，后足加宽并缩短口鼻。
- 禁止项：真实鱼类、长鱼尾、直立长耳、透明鳍、鳞片网、眼睛高光。

### E75 盐喙喷兽 / saltbeak-spitter

- 主体：前低后稳的短身喷兽，头部压成一块钝圆铲形盐喙，两侧各覆盖一枚宽鳃甲；以盐屑喷吐承担远程职责。
- 配色：湿沙灰棕主身、浅礁灰盐喙、柔和海蓝侧腹、旧铜灰绿鳃甲、深海褐灰描边；眼睛无高光。
- 复用来源：E49 沼冠伏兽；保留低伏四足和短圆躯干。
- 差异化改动：沼冠改为铲形盐喙，背部植被改为双侧鳃甲，四足收成短粗礁足。
- 禁止项：肿囊、喷泉口、长鸟喙、气泡、密集孔洞、眼睛高光。

### E76 礁盾驮兽 / reefshield-carrier

- 主体：宽肩四足精英，两枚厚圆礁盾从肩侧向外展开，前足像短柱，尾端收成一片扇形短尾。
- 配色：冷礁灰主甲、湿沙灰棕躯干、柔和海蓝腹面、旧铜灰绿盾缘、深海褐灰描边；眼睛无高光。
- 复用来源：E52 黑水钳兽；保留前重宽肩、粗前足与低重心。
- 差异化改动：钳部结构收为柱状前足，背甲拆成两枚圆礁盾，尾部缩短并压成扇形。
- 禁止项：真实海龟、整面塔盾、尖刺甲、巨锚、条纹盾面、眼睛高光。

### B76 盐冠礁王 / saltcrown-reefking

- 主体：前重后稳的巨型礁壳兽，额部覆盖一块宽盐冠，背部只有三块相互错开的扇形甲板，两只前掌宽厚如浅滩铲板。
- 配色：深湿沙灰棕主身、浅礁灰盐冠与背甲、柔和海蓝侧腹、旧铜灰绿甲缘、深海褐灰描边；眼睛无高光。
- 复用来源：B52 黑水铠鳄；保留宽体短腿、巨大前掌和三段背甲。
- 差异化改动：鳄形头颚改为盐冠楔头，尾巴压短，湿地背甲改为扇形盐礁甲板。
- 标志技能：盐冠冲压；低血时三块背甲闭合并获得短时减伤。
- 禁止项：写实鳄鱼或螃蟹、外露长牙、藤壶噪点、发光盐晶、尖刺冠、眼睛高光。

## 4. 浪蚀岩岸设计卡

### E77 蚀岸颚兽 / shoremaw-beast

- 主体：贴地四足异兽，短头由上下两块圆钝海蚀颚板构成，一侧肩部覆盖单块厚岩甲，尾部短而低。
- 配色：冷岩灰主甲、深潮蓝灰躯干、灰绿腹面、少量盐壳灰切面、深海褐灰描边；眼睛无高光。
- 复用来源：E65 孔背岩兽；保留贴地四足与前低后高背线。
- 差异化改动：双侧暗孔改为上下颚板与单肩岩甲，背部孔洞全部移除，头身压得更短。
- 禁止项：鳄鱼写实比例、岩洞孔眼、尖牙排、简单横带、泡沫、眼睛高光。

### E78 裂鳍疾兽 / splitfin-runner

- 主体：低伸长体的疾行异兽，短粗尾端分成上下两片厚鳍板，前足贴地、后足发力，头部保持钝圆。
- 配色：深潮蓝灰主身、冷岩灰鳍板、灰绿腹面、盐壳灰转折面、深海褐灰描边；眼睛无高光。
- 复用来源：E66 裂尾疾兽；保留低身、短腿和分叉尾骨架。
- 差异化改动：岩尾改为宽厚潮鳍，头背增加一块短岸脊，整体替换为冷海配色。
- 禁止项：真实鱼鳍、细长犬腿、透明尾膜、水波条纹、发光边缘、眼睛高光。

### E79 潮幕甲蛾 / tidecloak-shellmoth

- 主体：短圆甲蛾，两片厚重潮幕翼像海蚀壳板向后折叠，颈部覆盖一整块盐灰绒领，六足贴地不悬浮。
- 配色：冷岩灰翼面、深潮蓝灰折翼暗面、灰绿躯干、盐壳灰绒领、深海褐灰描边；眼睛无高光。
- 复用来源：E67 冷渣甲蛾；保留短圆虫体和两片宽折翼。
- 差异化改动：炉渣翼改为圆角潮蚀壳翼，颈绒改为盐灰厚领，足部加宽并明确接地。
- 禁止项：透明翅、翅脉网、漂浮姿态、发光粉尘、规则翼纹、细触角。

### E80 岸脊锤兽 / shoreback-mauler

- 主体：前倾双足精英，背部竖起一块厚高岸脊板，两条前臂末端像圆钝礁锤，肩部以一整块横岩承力。
- 配色：深潮蓝灰主身、冷岩灰背板、灰绿肩岩、盐壳灰磨损面、深海褐灰描边；眼睛无高光。
- 复用来源：E68 炉脊锤兽；保留前倾双足、粗尾、厚背板和锤臂骨架。
- 差异化改动：炉脊改为波蚀岸脊板，肩甲改为横向礁岩，暗赭配色完全替换为冷海灰绿。
- 禁止项：龙翼、尖爪、浪花特效、岩纹裂网、密集甲片、发光眼。

### B80 断潮壳龙 / tidebreak-shellback

- 主体：粗桩四足壳龙，头部覆盖宽海蚀岩冠，两片折叠壳鳍贴住肩侧，背部只有三层相互错开的潮蚀甲板。
- 配色：深潮蓝灰主身、冷岩灰壳鳍、灰绿甲板、盐壳灰切面、深海褐灰描边；眼睛无高光。
- 复用来源：B68 黯脉壳龙；保留四足壳龙、折叠翼面、粗尾和三层背甲。
- 差异化改动：岩冠改为圆钝海蚀冠，壳翼缩宽为折叠鳍板，全部替换为冷海岸配色并移除暗橙切面。
- 标志技能：壳翼震击；低血时压低壳鳍连续短扑两次。
- 禁止项：展开飞翼、写实龙鳞、海浪特效、密集尖刺、发光纹路、眼睛高光。

## 5. 潮蚀遗垒设计卡

### E81 潮垒兽卒 / tidewall-orc

- 主体：约 2.2 头身的 Q 版潮垒兽人，大而宽的方圆头、短耳、短颈、宽手脚和两枚极短圆钝下獠牙，双手持一把短柄盐石刀。
- 配色：低饱和蓝灰绿皮肤、深蓝灰石护肩、氧化铜绿衣片、盐壳灰武器、深海褐灰描边；眼睛无高光。
- 复用来源：E69 烬炉地精；保留短身近战姿态、双手武器和脚底基线。
- 差异化改动：长尖耳改为短圆耳，圆头改为宽方颚，增加短钝下獠牙，灰烬石和棕衣改为盐石与旧铜配色。
- 禁止项：哥布林长耳、成人兽人比例、写实肌肉、长獠牙、复杂皮甲、眼睛高光。

### E82 盐刃掠手 / saltblade-raider

- 主体：约 2.1 头身的低伏兽人掠手，宽头前倾，短粗四肢，两手各持一枚短小内弯盐石钩刃。
- 配色：蓝灰绿皮肤、盐壳灰双刃、氧化铜绿衣片、深蓝灰护腕、深海褐灰描边；眼睛无高光。
- 复用来源：E70 灰刃斥候；保留低伏奔跑、双短刃和紧凑脚底关系。
- 差异化改动：地精长耳改为兽人短耳，头颅加宽，下颚增加两枚短钝牙，铲刃改为内弯盐石钩刃。
- 禁止项：盗贼兜帽、细长匕首、成人肌肉、密集皮带、夸张獠牙、眼睛高光。

### E83 礁盘投手 / reefdisc-thrower

- 主体：约 2.2 头身的短身兽人投手，一手在头侧举起扁圆盐礁盘，另一条短臂向前平衡，腰侧只挂一枚备用小盘。
- 配色：蓝灰绿皮肤、盐壳灰礁盘、氧化铜绿衣片、深蓝灰绑箍、深海褐灰描边；眼睛无高光。
- 复用来源：E71 炉罐投手；保留单手高举投掷物、前手平衡和腰侧备用物结构。
- 差异化改动：地精头部改为宽方兽人头，投掷罐改为扁圆礁盘，衣片和绑带替换为潮垒材质。
- 禁止项：飞盘玩具感、圆盾误读、发光符文、弹药串、长横臂、眼睛高光。

### E84 沉甲护卫 / sunkenplate-guard

- 主体：约 2.2 头身的宽体兽人精英，左臂持圆角盐石盾，右手持短柄方锤，两块旧铜肩甲横向压低身形。
- 配色：深蓝灰绿皮肤、氧化铜绿肩甲、盐壳灰盾锤、深蓝灰内衬、深海褐灰描边；眼睛无高光。
- 复用来源：E72 黑铁监工；保留宽肩短身、粗手脚和重型护卫姿态。
- 差异化改动：双手锤改为盾锤组合，黑铁肩架改为圆角旧铜肩甲，地精长耳与圆头改为兽人短耳宽颚。

### B84 潮垒酋领 / tidewall-chieftain

- 主体：约 2.25 头身的宽体兽人首领，以横向胸肩和巨大手脚体现 Boss 级别；断礁额冠、双层旧铜肩板和短柄宽潮石锤组成首领剪影。
