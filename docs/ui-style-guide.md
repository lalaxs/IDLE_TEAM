# 青丘远征 UI 视觉规范

## 视觉方向

厚描边的卡通冒险界面。深炭灰承载常驻 HUD、背包与导航，奶油纸面承载养成、商店、关卡和详情。浅赭色标题带建立层级，暖黄按钮突出主要操作，蓝灰按钮承载整理、筛选和返回。图标保持彩色、饱满的轮廓；角色和装备使用游戏现有美术。

## 字体与排版

- 统一使用寒蝉全圆体 F 的圆润粗体，本地字体名 Qingqiu Round；正文 14px / 1.5，标准字重 700。中文、数字、按钮及战斗飘字共享字体，加载期间回退到微软雅黑、苹方。
- 弹窗标题 22px，页面标题 18px，主按钮 16px，资源数字 15px，紧凑标签与辅助信息 12px。
- 标题、深底数字、导航文字和按钮使用短而实的深色文字描边；浅底正文和长说明不描边。
- 数字使用等宽数字；金额完整显示现有缩写，消耗和属性名允许换行。
- 间距使用 4 / 8 / 12 / 16 / 24px。页面边距 8–12px，卡片内边距 8–12px，列表间距 8px。

## 组件

### 按钮

按钮外框 2px，主按钮外框 3px，圆角 10–12px。顶部使用一道浅色内高光，底部保留 3px 实色阴影。紧凑页签与工具按钮高 36px，常规操作高 40px，主要动作高 44px；相邻控件保留清楚间距，避免误触。按下向下移动 2px并收短底部阴影；键盘焦点使用独立外框。禁用为灰蓝底与清楚的浅色文字，去掉凸起阴影。

主操作用黄色，次操作用蓝灰色。挑战及危险操作用珊瑚红，设置内清档保持分隔后的次要危险入口。每个局部任务只强调一个主要操作。

### 面板与弹窗

深色框架使用 3px 深描边、1–2px 内亮边，圆角 12px。浅色弹窗使用奶油纸面、浅赭标题带、3px 深描边，圆角 18–20px。标题居中，右侧红色关闭控件不挤压标题。背景遮罩为 62% 深色，正文无需毛玻璃。

详情按标题、对象摘要、分组信息、操作区排列。长内容纵向滚动，主操作保留可达位置。沿用现有退出、焦点和数据更新行为。

### 卡片与装备槽

装备采用方形格、2px 外轮廓、品质色内边与低饱和底色。选中用金色框和勾选标记；空槽使用深灰凹槽或灰蓝占位。卡片保留触控尺寸。

英雄卡以角色图像为主体，底部深色名牌显示名称、专精和等级。战斗小队按五列排列，以 56px 主动技能图标为主体，图标下方依次放 13px 角色姓名和 7px 生命条，不显示头像与等级。外圈显示技能冷却恢复进度，生命条低生命转红。小队格使用透明底，不叠加卡片外框；点击整格进入阵容编辑。

### 导航与分类

底部五个入口使用统一的彩色厚描边图标：背包、商店、炼金、英雄、关卡。图标 38px，文字 14px。选中项为桃色底板与深色文字底签，其余为炭灰底。

二级分类统一使用深灰轨道，未选中蓝灰底，选中暖黄底。背包纵向分类保留排列方向，但共享颜色、圆角、描边和选中语义。

### HUD 与反馈

顶部资源栏高 42px（另加安全区），资源项与设置按钮高 36px。整栏为透明底，每个资源项保留独立的深色圆角小底板、描边与内高光，悬浮在场景上；右侧保留设置按钮。关卡编号和名称位于资源下方的空中区域，居中单行排列，透明底与深色文字描边保证可读性。派遣入口在有进行中任务或奖励时显示于右上角。战斗画布从屏幕顶部连续铺到小队技能栏上沿。宝箱、讨伐进度和 36px 倍速按钮悬浮在画面底部，使用透明容器，背景连续延伸到控件后方；资源项、设置、倍速按钮与进度轨道保留各自的底色。进度和倍速靠下对齐，文字使用深色描边，保持战斗主体清楚可见。进度轨道 10px，进度为绿色，首领战为珊瑚红，进度文字位于轨道上方。奖励用暖黄，结果提示使用稳定的深色底板。

## 页面应用

| 表面 | 主要任务 | 样式与布局 |
| --- | --- | --- |
| 常驻 HUD | 读取战况、领取宝箱 | 空中关卡标签、下方进度操作栏、大技能图标与生命条 |
| 背包 | 浏览、筛选和管理装备 | 深色框架、品质方格、蓝灰工具按钮 |
| 商店 | 选购补给与能力 | 奶油纸面、单列商品、黄色购买按钮 |
| 炼金 | 选择材料并加工 | 纸面与深色工艺槽、固定操作区 |
| 英雄 | 选择与培养角色 | 彩色头像卡、纸面属性与蓝灰展示区 |
| 关卡与副本 | 选择挑战与派遣 | 纸面章节卡、统一分段分类与状态按钮 |
| 阵容与设置 | 调整当前配置 | 赭色标题带、纸面内容、统一关闭控件 |
| 技能、天赋与装备详情 | 阅读并执行养成动作 | 分组纸面、品质图标、统一按钮 |

## 适配与动效

面向 360–430px 手机竖屏，桌面沿用项目的居中适配。短屏炼金页整体纵向滚动，为九格工艺台保留完整高度，向下滑动即可到达操作区；常规高度保留独立材料列表与底部操作区。安全区计入顶底栏。横屏沿用旋转提示。控件过渡为 120ms，弹窗进入为 180ms；遵循游戏的减弱动效设置与系统偏好。

颜色、尺寸、描边、阴影和字体以 `src/styles/theme.css` 为统一来源，具体组件在 `src/styles/components.css` 实现。
