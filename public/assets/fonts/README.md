# 游戏字体

## Qingqiu Round

游戏内置圆体基于 [寒蝉全圆体 F v3.200](https://github.com/Warren2060/ChillRound/releases/tag/v3.200) 的 Bold 字重，保留完整字形，使用 WOFF2 格式。字体家族名为 Qingqiu Round。

原作者：ChillType。字体按 SIL Open Font License 1.1 分发，完整许可见 [OFL.txt](OFL.txt)。

## Changa One

战斗伤害与治疗数字使用 Changa One Regular，字体文件来自 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/changaone)。字体家族名为 Changa One。

原作者：Eduardo Tunni。字体按 SIL Open Font License 1.1 分发，完整许可见 [OFL-Changa-One.txt](OFL-Changa-One.txt)。
